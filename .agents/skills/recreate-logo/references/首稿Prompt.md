# 首稿 Prompt

用于根据唯一权威参考图生成 Logo 复刻首稿。

```text
Use case: logo-brand
Asset type: faithful Logo recreation

Input images:
Image 1 is the only authoritative reference.

Primary request:
先在内部认真分析 Image 1，然后完整还原其中所有可见内容。

必须匹配：
- 构图和图形元素
- 文字及字体效果
- 配色和视觉效果
- 比例、位置、间距和留白
- 图层顺序和遮挡关系
- 背景
- 画布宽高比

保持参考图原有风格。
参考图中存在的渐变、阴影、纹理、描边或立体效果应保留；
参考图中不存在的效果不得自行添加。

Constraints:
不要重新设计、简化或美化。
不要增加、删除或替换任何元素。
不要添加额外文字、图标、边框或水印。
文字必须逐字准确。
最终结果应尽可能接近 Image 1。

Output:
<填写本次确认的尺寸、格式和背景要求>
```
