- 执行 ID：不适用；本次未调用生成模型。
- 变换步骤：从回放测试 v2 的三个文字区裁切并以 `15%` 阈值提取蒙版 → 分别缩放到父资产对应文字区域 → 在父资产副本上仅清除三个授权文字区并写入新文字 → 以 `PNG24` 输出 `1200 x 1200 RGB PNG`。
- 实际命令：

```bash
PARENT='Logo案例/阿川家Logo/Logo文件/黄底文字版-1200.png'
DRAFT='Logo案例/杨荣洋Logo/Logo文件/杨荣洋-黄底文字版-回放测试-v2.png'
OUTPUT='Logo案例/杨荣洋Logo/Logo文件/杨荣洋-黄底文字版-回放测试-v3.png'

test ! -e "$OUTPUT"

magick \
  \( "$DRAFT" -crop '638x188+287+416' +repage \
     -colorspace Gray -threshold '15%' -negate -trim +repage \
     -filter Lanczos -resize '553x168!' \
     -write mpr:title +delete \) \
  \( "$DRAFT" -crop '600x37+320+626' +repage \
     -colorspace Gray -threshold '15%' -negate -trim +repage \
     -filter Lanczos -resize '366x31!' \
     -write mpr:english +delete \) \
  \( "$DRAFT" -crop '506x49+356+707' +repage \
     -colorspace Gray -threshold '15%' -negate -trim +repage \
     -filter Lanczos -resize '384x36!' \
     -write mpr:capsule_text +delete \) \
  "$PARENT" -alpha off -colorspace sRGB \
  -fill '#FBC902' \
  -draw 'rectangle 334,435 886,602 rectangle 416,617 781,647 rectangle 410,687 793,722' \
  \( -size '553x168' xc:'#201716' mpr:title \
     -alpha off -compose CopyOpacity -composite \) \
  -geometry '+334+435' -compose Over -composite \
  \( -size '366x31' xc:'#201716' mpr:english \
     -alpha off -compose CopyOpacity -composite \) \
  -geometry '+416+617' -compose Over -composite \
  \( -size '384x36' xc:'#201716' mpr:capsule_text \
     -alpha off -compose CopyOpacity -composite \) \
  -geometry '+410+687' -compose Over -composite \
  -alpha off -colorspace sRGB -type TrueColor -strip \
  "PNG24:$OUTPUT"
```

- 输入规格与 SHA-256：根权威参考 `2676 x 814 RGBA PNG`，`7aeb746598eb432d0738be44d20eed2fb0dcddc62503773f4e2aba3d60e5d823`；不可变底图 `1200 x 1200 RGB PNG`，`f2c4627689c652d7c47c0ede3d2476d9d971faf1d410d726a2bb0b860b32eb96`；文字提取源 `1200 x 1200 RGB PNG`，`2a27c42abda2252f500a72de8e5c4766a3fac794759841f2694b7a8abb73c8f1`。
- 输出规格与 SHA-256：`1200 x 1200`、8-bit RGB PNG、3 通道、无透明通道；`53ffe5f46b99b381bae9d0deca15e2a130544eac1b6d5ab7f460d76144c44e1d`。
- 几何验证：整体前景 `553 x 304 +334 +435`；标题 `553 x 168 +334 +435`；英文 `366 x 31 +416 +617`；胶囊 `527 x 67 +341 +672`。
- 像素验证：相对不可变底图共改变 `64,721` 像素；标题区 `49,343`、英文区 `8,648`、胶囊文字区 `6,730`，三者之和等于总差异；授权区域外 RGB 非零差分像素为 `0`。
