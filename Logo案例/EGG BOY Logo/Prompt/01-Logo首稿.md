# EGG BOY Logo 首稿 Prompt

- 用途：根据唯一权威参考图生成完整 Logo 复刻首稿
- 顶层模式：复刻
- 输入图片：`Logo案例/EGG BOY Logo/Logo文件/参考图.png`
- 输出图片：`Logo案例/EGG BOY Logo/Logo文件/EGG-BOY-复刻-v1.png`

## 实际 Prompt

```text
Use case: logo-brand
Asset type: faithful Logo recreation

Input images:
Image 1 is the only authoritative reference.

Primary request:
先在内部认真分析 Image 1，然后完整还原其中所有可见内容。

必须匹配：
- 构图和图形元素
- 文字及字体效果
- 配色和视觉效果
- 比例、位置、间距和留白
- 图层顺序和遮挡关系
- 背景
- 画布宽高比

保持参考图原有风格。
完整保留左侧拟人鸡蛋服务员、帽子、面部、四肢、手套、行走姿态、托盘、餐点、小旗和黄色放射线。
完整保留右侧黄色圆角矩形、两行粗体文字“EGG”和“BOY”，以及字母 O 的白色蛋白和黄色蛋黄造型。
小旗上的微小标记按参考图可见形态忠实保留，不推测、不改写、不替换。
保持白色、蛋黄色和深蓝黑三色视觉体系。
参考图中存在的细节和边缘效果应保留；参考图中不存在的渐变、阴影、纹理、描边或立体效果不得自行添加。

Constraints:
不要重新设计、简化或美化。
不要增加、删除或替换任何元素。
不要添加额外文字、图标、边框或水印。
文字必须逐字准确。
最终结果应尽可能接近 Image 1。

Output:
生成一张 2048 x 2048 PNG，纯白不透明背景。保持参考图的正方形画布和原始留白比例。
```
