## 变换记录

### 1. 复刻首稿 v1

- 所属模式：`复刻`。
- 派生关系：EGG BOY 权威参考图 → EGG BOY 复刻 v1，`复刻`。
- 直接输入：`Logo案例/EGG BOY Logo/Logo文件/参考图.png`，作为唯一权威参考和工具实际输入。
- 输出资产：`Logo案例/EGG BOY Logo/Logo文件/EGG-BOY-复刻-v1.png`；未覆盖参考图。
- 内置生成源：`Logo案例/EGG BOY Logo/Logo文件/EGG-BOY-复刻-v1-内置生成源.png`。
- 实际 Prompt：[[Logo案例/EGG BOY Logo/Prompt/01-Logo首稿|Logo 首稿 Prompt]]。
- 工具与模型：内置 `image_gen`，`gpt-image-2`。
- 执行 ID：`exec-d4dc1d06-8475-4d22-93c0-9c3fb4596da4`。
- 变换步骤：使用唯一权威参考生成 `1254 x 1254` RGB PNG → 使用 ImageMagick Lanczos 强制缩放为 `2048 x 2048` → 关闭透明通道并归一化为 sRGB PNG24。
- 实际后处理命令：`magick <内置生成源> -filter Lanczos -resize '2048x2048!' -alpha off -colorspace sRGB -type TrueColor -strip 'PNG24:<v1>'`。
- 规格与 SHA-256：见资产清单。
- 已知边界：内置工具输出规格为 `1254 x 1254`，与 Prompt 请求的 `2048 x 2048` 不同；v1 通过确定性后处理达到目标规格。

### 2. 平面三色修正 v2

- 所属模式：`复刻`。
- 派生关系：EGG BOY 复刻 v1 → EGG BOY 复刻 v2，`修正`。
- 直接输入 / 直接父资产：`Logo案例/EGG BOY Logo/Logo文件/EGG-BOY-复刻-v1.png`。
- 输出资产：`Logo案例/EGG BOY Logo/Logo文件/EGG-BOY-复刻-v2.png`；未覆盖 v1。
- 实际 Prompt：不适用；本次未调用生成模型。
- 工具与模型：ImageMagick `magick`；模型不适用。
- 执行 ID：不适用；本次未调用生成模型。
- 变换步骤：建立 `#FFFFFF`、`#FCD209`、`#092339` 三色调色板 → 关闭抖动并把 v1 映射到该调色板 → 保持 `2048 x 2048` RGB PNG 规格。
- 实际命令：`magick <v1> +dither -remap <三色调色板> -alpha off -colorspace sRGB -type TrueColor -strip 'PNG24:<v2>'`。
- 规格与 SHA-256：见资产清单。
- 验证结果：输出颜色数为 `3`；背景为 `#FFFFFF`，黄色为 `#FCD209`，深蓝黑为 `#092339`。
