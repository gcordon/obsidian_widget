# Agent 角色管理

本目录同时保存当前项目的有效角色体系和多角色 Agent 的探索学习笔记。两者的执行效力不同，不得混用。

## 文档索引

### 当前项目

- [当前角色与流程](../当前角色与流程.md)：供用户日常查看的角色、流程和常见任务速查入口；它是 `AGENTS.md` 的派生摘要。
- [闲鱼与 GPT Image 2 项目角色体系](./当前项目/闲鱼与GPT-Image-2角色体系.md)：定义当前项目的 5 个角色、设计依据、权限和实际调用方式，作为详细说明与测试依据。

### 探索学习

- [多角色 Agent 协作探索](./探索学习/多角色Agent协作探索.md)：记录受控讨论、交叉评审、冲突收敛和停止条件的学习过程。
- [多角色 Agent 协作探索（简版）](./探索学习/多角色Agent协作探索-简版.md)：保存简化后的学习草案。

## 边界

- 项目执行时始终以根目录 [AGENTS.md](../AGENTS.md) 为唯一规则入口；根目录速查页和“当前项目”文档提供派生摘要、详细说明与测试证据，不构成独立规则源。
- “探索学习”文档只是笔记和候选方法，未经用户确认前不得自动应用到当前项目。
