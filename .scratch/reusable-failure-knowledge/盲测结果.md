# 可复用失败知识盲测结果

## 测试边界

1. 两名独立 Agent 只读执行，不参与规则生产。
2. 两名 Agent 均禁止读取 `.scratch/` 规划资料。
3. 作用域 Agent 只读取 `AGENTS.md`、失败工作台和 `ROLE-001`。
4. 图片分流 Agent 只读取 `AGENTS.md`、失败工作台、`IMG-001`、recreate-logo Skill、二次开发 Prompt 和修正 Prompt。
5. 图片分流 Agent 禁止读取 Logo 案例、图片、失败 Prompt、测试归档和预期答案。

## 作用域与角色分流

**结果：Pass**

1. 无上下文依赖的失败停止原则进入通用执行约束。
2. 项目内普遍适用的失败导航职责进入项目说明或项目规范。
3. 单一图片工作流的精确不变量分流进入对应 Skill 或专项规范。
4. 单次测试观测进入案例或测试记录，不得上浮。
5. 生产者自检不能作为完成依据，也不能用协调汇总或用户批准替代独立质量评估。
6. 恢复路径是由未参与生产的质量与实验评估 Agent 独立评估，`Pass` 且无缺失角色后才可完成。

## 图片失败分流

**结果：Pass**

1. 背景、边界或间距任一精确不变量偏差即命中 `IMG-001`。
2. 命中后立即停止使用全图生成修正精确不变量。
3. 适用条件未变化时，禁止仅加强相同 Prompt 后重试。
4. 恢复必须返回直接父资产，只在授权区域内执行局部编辑或确定性处理。
5. 决定分流无需读取失败 Prompt 或失败图片。
6. 精确不变量全部通过且只剩授权区域内普通视觉差异时，才可使用通用修正 Prompt。
7. 通过条件是可测量不变量一致且授权区域外无非预期变化。

## 验收结论

规则作用域、角色评估阻断和图片失败分流均能在不泄漏具体案例答案的情况下被稳定理解与执行。
