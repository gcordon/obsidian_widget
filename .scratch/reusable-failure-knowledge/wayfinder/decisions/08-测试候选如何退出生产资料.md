# 测试候选如何退出生产资料

## Question

失败测试候选如何退出生产入口并保留血缘？

## Decision

1. 失败候选从生产 Prompt 索引和正常生产入口移除。
2. 仍承担直接输入、SHA 或血缘证据的候选不得删除。
3. 这类候选移入非权威、禁止生产使用的隔离归档。
4. 生成记录保留真实派生关系并记录归档稳定路径。
5. 最终通过资产保留在正常资产目录。
6. 失败条目只引用证据，不复制 Prompt 或图片。
7. Git 已可靠保存且不再承担当前血缘的临时候选，可在验证后移出当前工作资料。

## Rationale

隔离同时满足生产安全和证据可验证性。

## Consequences

历史执行路径和命令不得因归档而改写；生产入口不得链接失败资料。

## Status

Accepted
