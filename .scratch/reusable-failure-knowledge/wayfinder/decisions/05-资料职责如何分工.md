# 资料职责如何分工

## Question

AGENTS、项目规范、Skill、案例和 Prompt 模板分别保存什么？

## Decision

1. AGENTS 定义通用作用域判断和已验证失败处理。
2. 项目失败知识工作台提供项目级导航。
3. 独立失败条目保存原子化警告和恢复路径。
4. Skill 在适用流程节点引用条目，不复制完整正文。
5. 案例和测试记录提供实际证据，不作为通用生产方法入口。
6. Prompt 模板只保存正确生产方法，不保存失败案例复盘。

## Rationale

单一事实源能避免规则漂移和失败素材进入生产入口。

## Consequences

跨层资料只链接权威文件，不复制失败条目正文或失败案例。

## Status

Accepted
