# Agent 命中已验证失败后如何行动

## Question

当前事实命中已验证失败时，Agent 必须如何行动？

## Decision

1. 实质工作前检查当前范围的已验证失败知识。
2. 命中触发条件时立即停止对应错误路径。
3. 适用条件未变化时不得重复已验证无效动作。
4. 停止后只执行已确认的恢复路径。
5. 没有恢复路径时停止并报告阻断。
6. 恢复或验收条件未满足时不得声称完成。

## Rationale

失败知识只有能强制改变后续动作，才具有防偏航价值。

## Consequences

Agent 不能把重试当作修复，也不能在恢复前结束任务。

## Status

Accepted
