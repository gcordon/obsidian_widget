# 每日图片练习启动 Prompt

> 每天开始练习时，把下面这段复制给 ChatGPT Project。今天先选一种 AI Logo 方法，再决定是否上传参考图或生成图。

```text
今天进行 AI Logo 生成方法练习。

请按我的 Obsidian 学习系统来指导我。

今日信息：
- 日期：
- 品牌名称：
- 行业 / 餐饮细分：
- Logo 类型：
- 目标风格：
- 用途：
- 今日练习方法：直接生成 / 参考图分析 / 参考图生成变体 / 上传旧图修改 / 局部修改 / 多方向生成 / 高清复原 / 矢量化准备
- 是否上传图片：无 / 参考图 / 旧 Logo / 生成结果图

请你先不要急着生成最终图，按步骤完成：

1. 先判断今天的方法应该怎么做：
   - 这个方法的目标是什么；
   - 需要我补充哪些信息；
   - 哪些地方最容易失败。

2. 分析图片或品牌需求：
   - 核心构图；
   - 图形主体；
   - 字体风格；
   - 主要颜色；
   - 辅助元素；
   - 哪些适合保留；
   - 哪些应该简化；
   - 它更像 Logo 还是插画。

3. 给出 3 个设计方向：
   - 一个稳妥可落地方向；
   - 一个更有记忆点方向；
   - 一个更简洁清楚方向。

4. 为每个方向写一段可直接用于生成图片或修改图片的 Prompt。

5. 使用 Logo 质量检查标准告诉我：
   - 哪个方向最适合头像；
   - 哪个方向最适合招牌；
   - 哪个方向最适合包装贴纸；
   - 哪个方向最容易转 SVG。

6. 等我确认方向后，再继续生成或修改图片。
```

## 使用提示

- 如果你有参考图，先上传图，再发这段 Prompt。
- 如果你没有参考图，先提供品牌名、行业和用途。
- 如果今天练局部修改，一次只改一个问题。
- 不要一开始就让 GPT 直接生成最终图，先让它分析结构。
