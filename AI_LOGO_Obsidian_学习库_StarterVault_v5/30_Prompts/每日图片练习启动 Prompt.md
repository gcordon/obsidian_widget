# 每日图片练习启动 Prompt

> 每天开始练习时，把下面这段复制给 ChatGPT Project，然后上传参考图或生成图。

```text
今天进行 AI Logo / 图片设计练习。

请按我的 Obsidian 学习系统来指导我。

今日信息：
- 日期：
- 品牌名称：
- 行业：
- 目标风格：
- 用途：
- 今日练习类型：结构分析 / 风格替换 / 高清复原 / 矢量化 / 品牌延展
- 我会上传参考图或生成图。

请你先不要急着生成最终图，按步骤完成：

1. 分析图片或品牌需求：
   - 核心构图；
   - 图形主体；
   - 字体风格；
   - 主要颜色；
   - 辅助元素；
   - 哪些适合保留；
   - 哪些应该简化；
   - 它更像 Logo 还是插画。

2. 给出 3 个设计方向：
   - 一个稳妥可落地方向；
   - 一个更有创意方向；
   - 一个适合商业交付方向。

3. 为每个方向写一段可直接用于生成图片的 Prompt。

4. 使用 [[Logo 质量检查表]] 的标准告诉我：
   - 哪个方向最适合头像；
   - 哪个方向最适合招牌；
   - 哪个方向最适合包装贴纸；
   - 哪个方向最容易转 SVG。

5. 等我确认方向后，再继续生成或修改图片。
```

## 使用提示

- 如果你有参考图，先上传图，再发这段 Prompt。
- 如果你没有参考图，先提供品牌名、行业和用途。
- 不要一开始就让 GPT 直接生成最终图，先让它分析结构。
