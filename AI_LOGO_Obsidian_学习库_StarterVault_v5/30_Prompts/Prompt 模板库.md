# AI Logo Prompt 方法库

> Prompt 不只是收藏。当前阶段按「AI Logo 生成方法」来整理：直接生成、参考图分析、变体、改图、局部修改、多方向、高清复原、矢量化准备。

## 使用顺序

1. 用户对 AI 说：`开始今天学习`。
2. AI 读取 [[学习进度与任务追踪]]，选择今天要练的方法。
3. AI 从本页挑选或改写对应 Prompt 给用户。
4. 用户在 ChatGPT 生成、分析或修改 Logo。
5. 用户把结果、问题、图片路径或截图告诉 AI。
6. AI 更新 Daily、学习进度，并判断是否要整理进 [[案例复盘库]] 或本页。

协作规则：[[AI 陪练学习流程]]

## 01 直接生成 Logo Prompt

适合：没有参考图，只有品牌名、行业、风格和用途。

使用案例：

- [[Prompt - 饭团小满 直接生成 Logo]]

```text
我今天要练习 AI 生成 Logo 的「直接生成」方法。

品牌名称：[填写]
行业 / 餐饮细分：[小吃 / 奶茶 / 咖啡 / 烧烤 / 甜品 / 快餐 / 地方菜]
Logo 类型：[外卖头像 / 吉祥物 / 圆形徽章 / 门店招牌 / 包装贴纸]
目标风格：[可爱 / 现代 / 复古 / 高级简约 / 烟火气 / 国潮]
主要用途：[外卖头像 / 门店招牌 / 包装 / 社交媒体]

请先分析：
1. 这个 Logo 最适合的核心图形；
2. 中文品牌名和字体可能出错的地方；
3. 推荐配色和不推荐配色；
4. 如何避免变成复杂插画；
5. 缩小到 64x64 时要注意什么。

然后给我一个可直接用于图片生成的 Prompt。
```

常见失败点：

- 画面太复杂，不像 Logo。
- 中文品牌名错误。
- 背景太花。
- 细节太多，缩小后看不清。

## 02 参考图分析 Prompt

适合：上传喜欢的 Logo、竞品 Logo、客户给的参考图。

```text
请分析这张 Logo 参考图。注意：不要照抄，只做结构和风格学习。

请按下面格式输出：

1. 核心构图：
2. 主体图形：
3. 字体 / 文字风格：
4. 主要颜色：
5. 辅助元素：
6. 它为什么像 Logo，而不是插画：
7. 哪些设计语言可以学习：
8. 哪些地方不能照抄：
9. 如果换成新品牌「[品牌名]」，应该如何重新设计：
10. 可用于新品牌生成的 Prompt：
```

常见失败点：

- 只说好看，不拆结构。
- 直接要求 AI 复制参考图。
- 没有区分「可学习」和「不能照抄」。

## 03 参考图生成变体 Prompt

适合：借鉴参考图的结构或风格，但要换成自己的品牌和元素。

```text
请基于我上传的参考 Logo，生成一个新品牌 Logo 变体。

参考图只用于学习构图、线条、配色和风格，不要照抄图形、文字或品牌元素。

新品牌名称：[填写]
行业 / 餐饮细分：[填写]
新核心图形：[填写]
目标用途：[头像 / 招牌 / 包装贴纸]

请保留：
- 参考图的整体风格气质；
- 类似的简洁程度；
- 类似的颜色控制方式。

请替换：
- 品牌名；
- 主体图形；
- 文字排版；
- 辅助元素。

输出一个新的 Logo 生成 Prompt，并说明它和参考图有哪些不同。
```

常见失败点：

- 参考图相似度太高。
- 新品牌信息不清楚。
- 只换文字，没有换结构和主体。

## 04 上传旧图修改 Prompt

适合：已有旧 Logo、模糊 Logo、客户给的旧图，需要改清晰、改风格或改颜色。

```text
请基于我上传的旧 Logo 做修改。

修改目标：[改清晰 / 改颜色 / 改风格 / 简化细节 / 更像专业 Logo]

必须保留：
- [例如：品牌名]
- [例如：主体图形]
- [例如：整体构图]

需要修改：
- [例如：线条更干净]
- [例如：颜色减少到 2-3 种]
- [例如：背景去掉]
- [例如：文字更清楚]

要求：
1. 不要把 Logo 改成完全不同的图；
2. 保留原始识别特征；
3. 让它更适合头像、招牌或包装；
4. 输出高清 PNG；
5. 修改后说明改了哪些地方。
```

常见失败点：

- AI 重新设计过头。
- 旧 Logo 的识别特征丢失。
- 改图目标写得太泛。

## 05 局部修改 Prompt

适合：初稿大体可用，只需要改一两个细节。

```text
请只修改这个 Logo 的指定部分，不要改变整体构图。

需要修改：
- [文字 / 颜色 / 边框 / 主体表情 / 辅助元素 / 背景]

保持不变：
- [整体构图]
- [主体图形]
- [Logo 类型]
- [主风格]

修改目标：
- [更清楚 / 更可爱 / 更现代 / 更适合外卖头像 / 更适合矢量化]

要求：
1. 不要添加无关元素；
2. 不要大改构图；
3. 保持 Logo 感；
4. 修改后告诉我具体改了哪里。
```

常见失败点：

- 一次要求改太多。
- 没写清楚哪些保持不变。
- AI 把整体重画了。

## 06 多方向生成 Prompt

适合：不知道哪种风格适合，先探索 3 个方向。

```text
请基于下面的品牌需求，生成 3 个不同 Logo 方向。

品牌名称：[填写]
行业 / 餐饮细分：[填写]
用途：[头像 / 招牌 / 包装]
目标用户：[填写]
必须包含：[填写]
不能出现：[填写]

请给出 3 个方向：
1. 稳妥可用方向；
2. 更有记忆点方向；
3. 更简洁高级方向。

每个方向请输出：
- 方向名称；
- 核心图形；
- 配色；
- 字体 / 文字建议；
- 适合用途；
- 可直接用于图片生成的 Prompt；
- 最大风险。

最后推荐一个最值得继续迭代的方向。
```

常见失败点：

- 三个方向差异太小。
- 只追求好看，不判断用途。
- 没有选出下一步继续迭代的方向。

## 07 高清复原 Prompt

独立模板：[[Prompt - 高清复原模板]]

快速版：

```text
请参考这张模糊 Logo，将它高清复原并重新绘制。

要求：
1. 保留原始构图、比例、颜色和品牌识别；
2. 去除模糊、锯齿和压缩痕迹；
3. 重绘清晰线条和边缘；
4. 文字尽量清晰可读；
5. 不添加新图形、新背景或水印；
6. 输出高清 PNG。

复原后请说明：
- 哪些地方成功保留；
- 哪些地方可能与原图不同；
- 是否适合继续转 SVG。
```

常见失败点：

- 复原变成重新设计。
- 文字被改错。
- 细节过度美化。

## 08 矢量化准备 Prompt

适合：准备进入 SVG / PDF / AI / EPS 之前，先判断 Logo 是否适合转矢量。

```text
请检查这个 Logo 是否适合后续转成 SVG / PDF / AI 文件。

请从以下角度判断：
1. 线条是否干净；
2. 色块是否明确；
3. 颜色是否能控制在 2-4 种；
4. 文字是否需要重新排版或手动处理；
5. 是否有太多渐变、阴影、纹理或细节；
6. 缩小后是否还能识别；
7. 哪些地方应该先简化再转矢量。

最后请输出：
- 是否适合矢量化：适合 / 暂不适合；
- 修改建议；
- 下一轮改图 Prompt。
```

常见失败点：

- 把 PNG 误认为已经是可编辑 AI 文件。
- 没有先简化复杂细节。
- 忽略文字需要单独处理。

## Prompt 方法评分

每个 Prompt 用这 5 项判断是否值得沉淀：

| 维度 | 问题 |
|---|---|
| 方法清晰 | 它对应哪一种生成或改图方法？ |
| 稳定性 | 多次使用是否能产出相似质量？ |
| 可替换性 | 换品牌名、品类、风格后是否仍然可用？ |
| 真实可用性 | 是否能产出适合头像、招牌或包装的 Logo？ |
| 案例支撑 | 是否至少有一个练习或案例验证？ |
