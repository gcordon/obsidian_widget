# 餐饮 Logo Prompt 包

> Prompt 不只是收藏。每个 Prompt 都要经过案例验证，最终沉淀成可复用、可售卖、可教学的资产。

## 使用顺序

1. 用启动 Prompt 明确餐饮细分、Logo 类型和目标风格。
2. 用生成 Prompt 得到第一版图。
3. 用修改 Prompt 改文字、构图、线条和应用场景。
4. 练习结束后导出 Obsidian Markdown。
5. 每周把稳定 Prompt 提炼成独立笔记。

## 启动练习 Prompt

```text
我今天要练习一个餐饮 Logo。

餐饮细分：[小吃 / 奶茶 / 咖啡 / 烧烤 / 甜品 / 快餐 / 地方菜]
Logo 类型：[外卖头像 / 吉祥物 / 圆形徽章 / 门店招牌 / 包装贴纸]
品牌名称：[填写品牌名]
目标风格：[可爱 / 现代 / 复古 / 高级简约 / 烟火气 / 国潮]

请先帮我分析：
1. 这个方向最重要的商业用途是什么；
2. 核心图形应该是什么；
3. 中文文字容易出什么问题；
4. 配色应该如何控制；
5. 是否适合做成模板包。

然后给我一个可直接用于图片生成的 Prompt。
```

## 餐饮 Logo 生成 Prompt

```text
请为餐饮品牌「[品牌名]」设计一个专业 Logo。

餐饮细分：[小吃 / 奶茶 / 咖啡 / 烧烤 / 甜品 / 快餐 / 地方菜]
Logo 类型：[外卖头像 / 餐饮吉祥物 / 圆形徽章 / 门店招牌 / 包装贴纸]
目标风格：[填写风格]
核心图形：[填写图形，例如饭碗、厨师、咖啡杯、烤串、甜品]

要求：
1. 看起来像专业 Logo，不要变成复杂插画；
2. 适合外卖头像、门店招牌和包装贴纸；
3. 图形清楚，缩小后仍然可识别；
4. 中文品牌名尽量清晰可读；
5. 颜色控制在 2-4 种；
6. 背景简洁，不要水印；
7. 输出高清 PNG。
```

## 外卖头像 Prompt

```text
请把这个餐饮 Logo 方向设计成适合外卖平台头像的版本。

品牌名称：「[品牌名]」
餐饮细分：「[餐饮细分]」
核心图形：「[核心图形]」

要求：
1. 64x64 小尺寸下仍然清楚；
2. 图形轮廓粗壮，避免小细节；
3. 中文品牌名可读，如果文字不稳定，优先保留无字图形版；
4. 使用高对比餐饮配色；
5. 适合圆形头像裁切；
6. 不要复杂背景，不要水印。
```

## 门店招牌 Prompt

```text
请把餐饮品牌「[品牌名]」设计成适合门店招牌的横版 Logo。

要求：
1. 中文品牌名远距离可读；
2. 图形和文字横向组合；
3. 适合招牌、菜单、包装和社交头像延展；
4. 颜色醒目但不要杂乱；
5. 输出高清 PNG；
6. 不要复杂背景，不要水印。
```

## mockup Prompt

```text
请基于这个餐饮 Logo，生成一个真实但简洁的应用场景 mockup。

应用场景：[门店招牌 / 外卖头像 / 包装贴纸 / 纸杯 / 菜单]
要求：
1. Logo 保持清楚，不要扭曲；
2. 场景简洁，突出 Logo；
3. 不要添加无关文字；
4. 适合放入作品集展示。
```

## Prompt 资产评分

每个 Prompt 用这 5 项判断是否值得沉淀：

| 维度 | 问题 |
|---|---|
| 稳定性 | 多次使用是否能产出相似质量？ |
| 可替换性 | 换品牌名、品类、风格后是否仍然可用？ |
| 商业性 | 是否能产出接近可售卖的 Logo？ |
| 易理解 | 以后自己或别人能否快速使用？ |
| 案例支撑 | 是否至少有一个案例验证？ |
