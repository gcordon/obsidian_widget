# Codex 任务 Prompt 模板库

这篇专门保存给 Codex 使用的任务指令。复制其中一段到 Codex 即可。

## 1. 第一次只读扫描

```text
请阅读 AGENTS.md 和当前 Obsidian vault。
不要修改任何文件。

请告诉我：
1. 当前 AI Logo 学习库有哪些主要模块；
2. 哪些文件应该作为 MOC、模板、案例、Prompt；
3. 建议我今天先学习哪 3 篇笔记；
4. 哪些内容适合以后交给你自动整理。
```

## 2. 整理 Inbox

```text
请整理 00_Inbox 中的内容。

要求：
1. 先列出你准备处理的文件；
2. 判断每条内容应该进入哪个文件夹；
3. 可复用 Prompt 放到 30_Prompts；
4. 长期知识放到 20_Knowledge；
5. 案例复盘放到 40_Cases；
6. 原始内容不要删除，可以移动到 Sources 或 90_Archive；
7. 修改前先给我计划。
```

## 3. 把长笔记拆成知识卡片

```text
请把这篇长笔记拆成适合 Obsidian 的知识卡片。

要求：
1. 每篇笔记只讲一个概念；
2. 放到 20_Knowledge；
3. 每篇包含：一句话解释、核心要点、适用场景、例子、常见错误、相关链接；
4. 保留原文，不要删除；
5. 在原文底部添加“已拆分笔记列表”。
```

## 4. 整理今天的 AI Logo 练习

```text
请帮我整理今天的 AI Logo 练习。

要求：
1. 读取 01_Daily 中今天的练习笔记；
2. 提取品牌信息、Prompt、生成结果和问题；
3. 生成一篇案例复盘，放到 40_Cases；
4. 如果有可复用 Prompt，整理到 30_Prompts；
5. 添加相关 Obsidian 双向链接；
6. 不要删除原始笔记。
```

## 5. 生成每周复盘

```text
请根据 40_Cases 中最近 7 天的案例，生成一篇本周 AI Logo 学习复盘。

要求：
1. 放到 70_Reviews；
2. 总结本周完成案例数量；
3. 找出最常见问题；
4. 总结本周最有效的 Prompt；
5. 给出下周重点练习方向；
6. 用 [[ ]] 链接相关案例和知识笔记。
```

## 6. 生成作品集页面

```text
请根据 40_Cases 中完成度最高的案例，帮我生成一个作品集页面。

要求：
1. 放到 60_Portfolio；
2. 每个作品包含品牌名称、行业、风格、设计关键词、主色、辅助色、输出格式；
3. 每个作品写一段设计说明；
4. 链接对应的案例复盘；
5. 不要编造没有记录的信息。
```

## 7. 检查孤立笔记

```text
请扫描整个 vault，找出没有任何 [[内部链接]] 的笔记。

先不要修改文件，只生成一份报告：
1. 哪些笔记是孤立的；
2. 它们可能应该链接到哪些主题；
3. 哪些笔记适合加入 AI Logo 设计 MOC。
```

## 8. 统一笔记格式

```text
请检查 20_Knowledge 里的所有笔记。
把格式统一为：

# 标题

## 一句话解释

## 核心要点

## 使用场景

## 例子

## 常见错误

## 相关链接

要求：
1. 不要改变原意；
2. 不要删除已有内容；
3. 如果某部分没有内容，保留标题并标注“待补充”；
4. 修改前先列出会修改哪些文件。
```
