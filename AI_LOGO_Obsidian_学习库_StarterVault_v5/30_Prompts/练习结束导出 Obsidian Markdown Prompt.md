# 练习结束导出 Obsidian Markdown Prompt

> 每次 ChatGPT 练习结束后，把下面这段发给它，让它输出可以直接放进 Obsidian 的内容。

```text
请把今天的练习整理成 Obsidian Markdown。

要求输出 5 部分：

A. 今日学习总结
- 今天练习了什么；
- 产生了哪些图；
- 最终选择了哪个方向；
- 最大问题是什么；
- 下一次要改进什么。

B. 放入 01_Daily 的每日练习记录
文件名建议：YYYY-MM-DD AI Logo 练习.md
请包含：
- 日期；
- 品牌名称；
- 行业；
- 目标风格；
- 用途；
- 参考图路径，若未知写“待补充”；
- 生成图路径，若未知写“待补充”；
- 最终图路径，若未知写“待补充”；
- 使用 Prompt；
- 结果评价；
- 下一步。

C. 放入 40_Cases 的案例复盘
文件名建议：案例 - 品牌名 Logo 复盘.md
请包含：
- 案例名称；
- 品牌信息；
- 设计目标；
- 参考图分析；
- Prompt 版本记录；
- 结果图链接占位；
- 问题记录；
- 质量评分；
- 我学到了什么；
- 下一次改进。

D. 可复用 Prompt
如果今天产生了可复用 Prompt，请整理成一篇 Prompt 笔记，适合放到 30_Prompts。
如果没有，就写“今天没有产生新的可复用 Prompt”。

E. 给 Codex 的本地整理指令
请生成一段可以复制给 Codex 的指令，用于整理今天的 Obsidian 文件。

请使用 Obsidian 双向链接，例如：
[[Logo 质量检查表]]
[[Prompt 模板库]]
[[AI Logo 常见错误]]
[[SVG AI PDF 工作流]]
[[图片案例记录规范]]

不要编造我没有提供的信息。
如果图片路径未知，请保留“待补充”。
```

## 输出后你应该怎么做

1. 把 B 部分复制到 `01_Daily/`。
2. 把 C 部分复制到 `40_Cases/`。
3. 把 D 部分复制到 `30_Prompts/`。
4. 把 E 部分留给 Codex 使用。
5. 图片文件保存到 `80_Assets/`。
