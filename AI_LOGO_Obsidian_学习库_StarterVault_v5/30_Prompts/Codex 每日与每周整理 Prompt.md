# Codex 每日与每周整理 Prompt

> Codex 不负责生图。Codex 负责整理本地 Obsidian 文件、Markdown、图片路径、Prompt、复盘和作品集。

## 第一次只读扫描

```text
请阅读 AGENTS.md 和当前 Obsidian vault。

不要修改任何文件。

请告诉我：
1. 当前 AI Logo 学习库有哪些主要模块；
2. 哪些文件是总入口、模板、Prompt、案例、图片素材；
3. 我今天应该从哪 3 篇笔记开始；
4. 这个 vault 中哪些部分适合由你定期整理。
```

## 每日整理 00_Inbox

```text
请阅读 00_Inbox 中最新的待整理 Markdown。

请帮我整理今天的 AI Logo 学习内容：

1. 将每日练习记录放到 01_Daily；
2. 将案例复盘放到 40_Cases；
3. 将可复用 Prompt 放到 30_Prompts；
4. 保留所有图片链接；
5. 添加必要的 [[双向链接]]；
6. 不要删除原始文件；
7. 修改前先告诉我会改哪些文件。
```

## 根据 Daily Note 生成案例复盘

```text
请阅读 01_Daily 中今天的 AI Logo 练习笔记。

请生成一篇案例复盘，放到 40_Cases。
要求：
1. 保留图片链接；
2. 保留 Prompt；
3. 记录问题和修改过程；
4. 使用 [[Logo 质量检查表]] 的评分维度；
5. 添加相关链接到 [[AI Logo 标准流程]]、[[AI Logo 常见错误]] 和 [[SVG AI PDF 工作流]]；
6. 不要编造没有记录的信息。
```

## 提取可复用 Prompt

```text
请扫描 01_Daily 和 40_Cases 中最近的练习记录。

要求：
1. 找出可以复用的 Logo Prompt；
2. 每个 Prompt 单独整理成一篇笔记；
3. 放到 30_Prompts；
4. 每篇包含：用途、适用场景、Prompt 正文、可替换变量、注意事项、使用记录；
5. 不要改动原始案例。
```

## 每周复盘

```text
请整理本周 AI Logo 学习内容：

1. 扫描 01_Daily 中本周的练习记录；
2. 扫描 40_Cases 中本周新增案例；
3. 生成一篇每周复盘，放到 70_Reviews；
4. 提取本周最有效的 Prompt，补充到 30_Prompts；
5. 检查 80_Assets 中有没有图片没有被案例引用；
6. 检查所有 ![[图片链接]] 是否断链；
7. 更新 60_Portfolio/我的作品集模板.md 或生成新的作品集草稿；
8. 不要删除任何图片。
```

## 检查图片断链

```text
请扫描所有 Markdown 文件。

检查其中的 ![[图片链接]] 是否能在 80_Assets 中找到对应文件。
生成一份断链报告，放到 70_Reviews。
不要移动或删除任何图片。
```

## 检查未复盘图片

```text
请扫描：
- 80_Assets/02_Generated

找出已经保存图片但没有对应案例复盘的文件。

```

## 生成作品集页面

```text
请根据 40_Cases 中完成度最高的案例，帮我生成一个作品集页面。

要求：
1. 放到 60_Portfolio；
2. 每个作品包含品牌名、行业、风格、设计说明、最终图链接和案例链接；
3. 不要编造没有记录的信息；
4. 如果缺少图片路径，标注“待补充”。
```
