# ChatGPT 图片生成与编辑 Prompt 模板库

## 1. 参考图分析 Prompt

```text
请分析这张 Logo 参考图，不要直接照抄。请从以下角度拆解：
1. 核心构图
2. 主体图形
3. 字体风格
4. 主要颜色
5. 辅助元素
6. 适合的行业
7. 可以保留的设计语言
8. 不建议保留的问题
9. 如果重新设计为新品牌，应该如何改
```

## 2. Logo 初稿生成 Prompt

```text
请根据以下信息生成一个专业 Logo 初稿。
品牌名称：{品牌名}
行业：{行业}
目标用户：{目标用户}
目标风格：{可爱 / 现代 / 魔幻 / 复古 / 高级简约}
核心图形：{想要的主体}
用途：头像、招牌、包装贴纸、社交媒体

要求：
1. Logo 风格，不要复杂插画；
2. 主体清楚，缩小后仍然可识别；
3. 线条干净，适合后期矢量化；
4. 颜色控制在 2-4 种；
5. 背景简洁；
6. 不要水印，不要多余文字；
7. 输出高清 PNG。
```

## 3. 风格变体 Prompt

```text
请基于当前 Logo 方向，生成 4 个风格变体：
1. 可爱圆润风
2. 现代极简风
3. 复古徽章风
4. 魔幻童话风

要求保留品牌识别核心，但改变线条、颜色、字体气质和辅助元素。
每个方向都要保持 Logo 感，不要变成复杂插画。
```

## 4. 局部修改 Prompt

```text
请只修改以下部分，不要改变整体构图：
需要修改：{例如：文字、颜色、边框、主体表情、辅助元素}
保持不变：{例如：圆形徽章结构、主体角色、主色调}
修改目标：{更清楚 / 更可爱 / 更现代 / 更适合矢量化}

要求：
1. 不要添加多余元素；
2. 保持线条清晰；
3. 保持 Logo 风格；
4. 输出高清 PNG。
```

## 5. 高清复原 Prompt

```text
请参考这张模糊 Logo，将它高清复原并重新绘制。
要求：
1. 尽量保留原始构图、颜色、比例和品牌结构；
2. 去除模糊、锯齿和压缩痕迹；
3. 重绘清晰的线条和边缘；
4. 文字尽量还原为清晰可读；
5. 不要改变核心风格；
6. 不要添加水印或额外元素；
7. 输出高清 PNG。
```

## 6. Logo 简化 Prompt

```text
请把这张 Logo 简化成更适合商业使用的版本。
要求：
1. 保留核心图形和品牌气质；
2. 删除过多小细节；
3. 增强大形识别度；
4. 确保缩小到 64×64 仍然清楚；
5. 颜色控制在 2-3 种；
6. 更像专业品牌标志，不要像插画。
```

## 7. 应用场景图 Prompt

```text
请把这个 Logo 应用到以下场景中：{包装贴纸 / 门店招牌 / 外卖头像 / 菜单 / 名片}
要求：
1. 保持 Logo 不变形；
2. 场景真实、干净、商业感强；
3. 不要改变 Logo 的文字；
4. 输出适合展示作品集的高清图。
```
