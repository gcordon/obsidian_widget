# Demo - 餐饮吉祥物 Logo Prompt 迭代

## 用途

用于餐饮品牌、外卖头像、门店招牌、包装贴纸的吉祥物 Logo 生成与修改。

## 适用场景

- 焖饭、烤肉饭、小吃、炸鸡、奶茶、甜品
- 需要可爱角色头像
- 需要中文品牌名
- 希望后续转 SVG

## 初版 Prompt

```text
参考这张餐饮品牌 Logo，将它高清重绘为专业餐饮吉祥物 Logo。
品牌名称是「{品牌名称}」。
行业是「{行业}」。
保留圆形头像结构、可爱角色、中文品牌名。
要求线条干净、边缘清晰、字体可读、颜色控制在 2-4 种。
整体适合外卖头像、门店招牌和包装贴纸。
不要复杂背景，不要水印，输出高清 PNG。
```

## 修改 Prompt：简化细节

```text
请继续简化这张 Logo，让它更像专业品牌标志而不是复杂插画。
要求：
1. 保留大形和品牌记忆点；
2. 减少面部和装饰小细节；
3. 线条更粗；
4. 缩小到 64×64 仍然清楚；
5. 颜色保持统一；
6. 适合后续转 SVG。
```

## 修改 Prompt：文字后期处理

```text
请生成一个无文字版本，只保留图形标志和圆形头像结构。
中文品牌名后期由我在 Figma 或 Illustrator 中重新排版。
```
