# START HERE：每天从这里开始

> 这是根目录快捷入口。第一次打开或不知道从哪里开始时，先看这里。

## 今天只打开这 3 个入口

1. [[AI 陪练学习流程]]：以后长期学习的协作规则。
2. [[每天从这里开始]]：开始今天的 AI Logo 方法练习。
3. [[学习进度与任务追踪]]：由 AI 读取和更新，不需要你手动维护。

## 今天怎么做

```text
对 AI 说：开始今天学习
→ AI 读取学习进度
→ AI 安排今天练什么
→ 你去 ChatGPT 生成或修改 Logo
→ 你把结果、问题、图片路径或截图告诉 AI
→ AI 更新 Daily、学习进度、Prompt 或案例
```

## 当前最重要的 8 种方法

| 方法 | 练什么 |
|---|---|
| 直接生成 Logo | 从品牌信息直接出初稿 |
| 参考图分析 | 拆解构图、颜色、字体、风格 |
| 参考图生成变体 | 借鉴结构或风格，但不照抄 |
| 上传旧图修改 | 改清晰、改风格、改颜色 |
| 局部修改 | 改文字、颜色、主体、边框 |
| 多方向生成 | 一次探索 3 个不同方向 |
| 高清复原 | 把模糊 Logo 变清晰 |
| 矢量化准备 | 判断是否适合 SVG / PDF / AI |
