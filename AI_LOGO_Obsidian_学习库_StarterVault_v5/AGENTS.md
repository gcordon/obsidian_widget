# AGENTS.md

你正在协助整理一个 Obsidian 学习知识库，主题是「AI 餐饮 Logo 商业学习」。

## 总目标

帮助用户把 AI Logo 练习沉淀成可长期学习、复盘和商业化的 Obsidian 知识库。当前主线是餐饮 Logo：通过每日练习、案例复盘、Prompt 沉淀和待售资产管理，长期形成餐饮 Logo 模板包、Prompt 包、风格包和素材包。

## 必读长期上下文

每次开始整理或改造本 vault 前，先读取：

- `90_System/AI_Context/README.md`
- `90_System/AI_Context/2026-05-26 项目目标与改造共识.md`

这两个文件记录了用户的长期目标：用 AI 学习和制作餐饮 Logo，并把学习成果沉淀成未来可售卖的模板包、Prompt 包、风格包和素材包。

## 工作原则

- 所有输出使用中文。
- 所有笔记使用 Markdown。
- 保留 Obsidian 内部链接格式，例如 `[[Logo 质量检查表]]`。
- 不要随意删除原始内容；原始材料优先放在 `Sources/` 或 `90_Archive/`。
- 不要修改 `.obsidian/` 设置目录，除非用户明确要求。
- 批量修改前，先说明计划和将要修改的文件。
- 每次只做一个明确任务。若用户明确要求系统性重构，可以改造整个 vault，但必须先说明计划、范围和将修改的文件。
- 文件命名要清楚、短、可读，不要使用过多符号。
- 不要把所有内容塞进一篇超长笔记；长期知识应拆成主题笔记。

## 文件夹规则

- `00_Index/`：学习首页、MOC、导航页。
- `00_Inbox/`：临时想法和未整理资料。

- `10_Learning_Plan/`：30 天计划、阶段计划。

- `60_Portfolio/`：待售资产、作品集和模板包规划。
- `70_Reviews/`：周复盘、月复盘、练习总结。
- `Templates/`：Obsidian 模板。
- `Sources/`：原始导入资料。

## 整理笔记时的格式

长期知识笔记建议包含：

1. 一句话解释
2. 核心要点
3. 适用场景
4. 例子
5. 常见错误
6. 相关链接

Prompt 笔记建议包含：

1. 用途
2. 适用场景
3. Prompt 正文
4. 可替换变量
5. 注意事项
6. 使用记录

案例复盘建议包含：

1. 品牌信息
2. 参考图分析
3. 第一次 Prompt
4. 第一次结果
5. 问题
6. 修改 Prompt
7. 最终结果
8. 质量评分
9. 学到什么
10. 下一次改进

## 用户常用任务

当用户说「整理今天的练习」时：
- 读取 `01_Daily/` 或 `00_Inbox/` 中的新内容。
- 生成或更新一篇案例复盘，放入 `40_Cases/`。
- 提取可复用 Prompt，放入 `30_Prompts/`。
- 如果有长期知识点，整理到 `20_Knowledge/`。
- 如果练习结果有商业潜力，补充到 `60_Portfolio/我的作品集.md` 的待售资产候选。

当用户说「检查我的 Logo」时：
- 使用 [[Logo 质量检查表]] 的维度检查。
- 重点关注：缩小后是否清楚、文字是否正确、是否像 Logo、是否容易转 SVG、是否适合头像/招牌/包装。

当用户说「生成本周复盘」时：
- 汇总 `40_Cases/` 中最近案例。
- 生成一篇周复盘，放入 `70_Reviews/`。
- 总结本周最稳定 Prompt、最有商业潜力案例、最值得推进的餐饮 Logo 资产方向。

当用户说「整理资产候选」时：
- 扫描 `40_Cases/` 和 `30_Prompts/`。
- 找出适合进入模板包、Prompt 包、风格包或素材包的内容。
- 更新 `60_Portfolio/我的作品集.md`。
- 不要编造案例结果；缺失内容标注为空或待用户补充。

## 禁止事项

- 不要编造用户没有提供的案例结果。
- 不要声称 PNG 就是可编辑 AI 文件。
- 不要鼓励直接照抄参考图。
- 不要删除用户原始文件。
- 不要同时改动大量文件而不给计划。


## 图片与 Logo 文件整理规则

- 图片素材统一放入 `80_Assets/`，不要散落在 vault 根目录。
- 参考图放 `80_Assets/01_References/`。
- AI 生成过程图放 `80_Assets/02_Generated/`。
- 最终图放 `80_Assets/03_Final/`。
- SVG、AI、PDF、EPS 放 `80_Assets/04_SVG_AI_PDF/`。
- 应用场景图、mockup 放 `80_Assets/05_Mockups/`。
- 不要随意删除图片。整理图片前先生成计划。
- 为图片生成案例笔记时，使用 Obsidian 图片嵌入格式，并指向真实存在的图片路径。
- Codex 不直接承担图片创作任务；图片生成、看图和局部修改优先交给 ChatGPT 网页版。Codex 负责整理文件、案例、Prompt 和复盘。


## 餐饮 Logo 商业学习流程规则

- ChatGPT 网页版 / Project 负责图片分析、图片生成、图片修改和审美判断。
- Obsidian 负责保存 Daily、Prompt、案例复盘、图片链接、周复盘和待售资产候选。
- Codex 负责本地 Markdown 整理、文件移动、链接补充、断链检查、周复盘生成和资产候选整理。
- zip 只用于阶段性备份和大版本更新，不作为每日同步方式。
