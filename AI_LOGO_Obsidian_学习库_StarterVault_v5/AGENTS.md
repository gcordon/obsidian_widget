# AGENTS.md

你正在协助整理一个 Obsidian 学习知识库，主题是「AI Logo 设计」。

## 总目标

帮助用户把 AI Logo 相关资料整理成可长期学习、复盘和输出的 Obsidian 知识库。这个 vault 不是普通项目，也不是 Notion 数据库，而是 Markdown 笔记系统。

## 工作原则

- 所有输出使用中文。
- 所有笔记使用 Markdown。
- 保留 Obsidian 内部链接格式，例如 `[[Logo 质量检查表]]`。
- 不要随意删除原始内容；原始材料优先放在 `Sources/` 或 `90_Archive/`。
- 不要修改 `.obsidian/` 设置目录，除非用户明确要求。
- 批量修改前，先说明计划和将要修改的文件。
- 每次只做一个明确任务，不要一次性重构整个 vault。
- 文件命名要清楚、短、可读，不要使用过多符号。
- 不要把所有内容塞进一篇超长笔记；长期知识应拆成主题笔记。

## 文件夹规则

- `00_Index/`：学习首页、MOC、导航页。
- `00_Inbox/`：临时想法和未整理资料。
- `01_Daily/`：每日学习记录。
- `10_Learning_Plan/`：30 天计划、阶段计划。
- `20_Knowledge/`：核心知识笔记，如结构、流程、常见错误。
- `30_Prompts/`：可复用 Prompt 模板。
- `40_Cases/`：Logo 案例复盘。
- `50_Workflows/`：SVG、AI、PDF、品牌延展等流程。
- `60_Portfolio/`：作品集和展示文案。
- `70_Reviews/`：周复盘、月复盘、练习总结。
- `Templates/`：Obsidian 模板。
- `Sources/`：原始导入资料。

## 整理笔记时的格式

长期知识笔记建议包含：

1. 一句话解释
2. 核心要点
3. 适用场景
4. 例子
5. 常见错误
6. 相关链接

Prompt 笔记建议包含：

1. 用途
2. 适用场景
3. Prompt 正文
4. 可替换变量
5. 注意事项
6. 使用记录

案例复盘建议包含：

1. 品牌信息
2. 参考图分析
3. 第一次 Prompt
4. 第一次结果
5. 问题
6. 修改 Prompt
7. 最终结果
8. 质量评分
9. 学到什么
10. 下一次改进

## 用户常用任务

当用户说「整理今天的练习」时：
- 读取 `01_Daily/` 或 `00_Inbox/` 中的新内容。
- 生成或更新一篇案例复盘，放入 `40_Cases/`。
- 提取可复用 Prompt，放入 `30_Prompts/`。
- 如果有长期知识点，整理到 `20_Knowledge/`。

当用户说「检查我的 Logo」时：
- 使用 [[Logo 质量检查表]] 的维度检查。
- 重点关注：缩小后是否清楚、文字是否正确、是否像 Logo、是否容易转 SVG、是否适合头像/招牌/包装。

当用户说「生成本周复盘」时：
- 汇总 `40_Cases/` 中最近案例。
- 生成一篇周复盘，放入 `70_Reviews/`。

## 禁止事项

- 不要编造用户没有提供的案例结果。
- 不要声称 PNG 就是可编辑 AI 文件。
- 不要鼓励直接照抄参考图。
- 不要删除用户原始文件。
- 不要同时改动大量文件而不给计划。


## 图片与 Logo 文件整理规则

- 图片素材统一放入 `80_Assets/`，不要散落在 vault 根目录。
- 参考图放 `80_Assets/01_References/`。
- AI 生成过程图放 `80_Assets/02_Generated/`。
- 最终图放 `80_Assets/03_Final/`。
- SVG、AI、PDF、EPS 放 `80_Assets/04_SVG_AI_PDF/`。
- 应用场景图、mockup 放 `80_Assets/05_Mockups/`。
- 不要随意删除图片。整理图片前先生成计划。
- 为图片生成案例笔记时，使用 Obsidian 图片嵌入格式：`![[路径/文件名.png]]`。
- Codex 不直接承担图片创作任务；图片生成、看图和局部修改优先交给 ChatGPT 网页版。Codex 负责整理文件、案例、Prompt 和复盘。


## v4 日常学习流程规则

- ChatGPT 网页版 / Project 负责图片分析、图片生成、图片修改和审美判断。
- Obsidian 负责保存长期知识、Prompt、案例复盘、图片链接和作品集。
- Codex 负责本地 Markdown 整理、文件移动、链接补充、断链检查和周复盘生成。
- zip 只用于阶段性备份和大版本更新，不作为每日同步方式。
