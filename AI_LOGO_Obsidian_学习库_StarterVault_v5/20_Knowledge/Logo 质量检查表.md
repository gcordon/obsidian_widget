# Logo 质量检查表

每次生成 Logo 后，用下面的表格打分。

评分标准：

- 1 分：很差
- 2 分：较弱
- 3 分：可用
- 4 分：较好
- 5 分：优秀

| 检查项 | 分数 | 备注 |
|---|---:|---|
| 缩小到 64×64 像素后是否清楚 |  |  |
| 黑白版本是否能识别 |  |  |
| 文字是否正确 |  |  |
| 图形是否太复杂 |  |  |
| 颜色是否统一 |  |  |
| 是否像 Logo，不像插画 |  |  |
| 是否容易转 SVG |  |  |
| 是否适合头像 |  |  |
| 是否适合招牌 |  |  |
| 是否适合包装贴纸 |  |  |
| 是否有品牌气质 |  |  |
| 是否有多余元素 |  |  |
| 是否有水印或乱码 |  |  |
| 整体完成度 |  |  |

## 快速判断标准

如果出现下面情况，需要继续修改：

- 文字错误
- 细节太碎
- 缩小后看不清
- 主体不明确
- 色彩太乱
- 更像插画，不像标志
- 没有品牌记忆点
- 无法转成干净矢量
