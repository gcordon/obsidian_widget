# 配色方法

Logo 颜色不要太多，一般控制在 2 到 4 种。

## 常见配色方向

| 类型 | 推荐颜色 |
|---|---|
| 餐饮 | 黄、橙、红、黑 |
| 咖啡 | 棕、米白、墨绿、浅粉 |
| 可爱 | 粉、奶油白、浅黄、浅蓝 |
| 科技 | 蓝、紫、青、黑 |
| 自然 | 绿、棕、米色 |
| 高级 | 黑、白、金、深蓝 |
| 魔幻 | 深紫、粉、金、月白、蓝灰 |
| 复古 | 棕、米色、橄榄绿、砖红 |

## 配色练习模板

```text
品牌名称：
行业：
目标风格：
主色：
辅助色：
点缀色：
背景色：
为什么这样配色：
```

## 配色原则

- 主色负责记忆点
- 辅助色负责层次
- 点缀色负责情绪
- 不要让所有颜色都很抢眼
- 黑白版也要成立
- 小尺寸下颜色对比要足够
