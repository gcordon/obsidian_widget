# 风格关键词库

## 6.1 可爱风

中文关键词：

```text
可爱型、圆润、亲切、腮红、软萌、儿童感、明亮、柔和、胖乎乎、友好、治愈、俏皮、卡通吉祥物
```

英文关键词：

```text
kawaii, cute mascot, rounded shape, soft pastel colors, chubby proportions, friendly smile, thick clean outline, blush cheeks, playful, adorable
```

适合行业：

- 奶茶
- 甜品
- 宠物
- 儿童品牌
- 小吃餐饮
- 虚拟 IP

## 6.2 魔幻风

中文关键词：

```text
魔幻、森林感、月亮、星星、精灵感、柔和神秘、童话氛围、梦幻、温柔、轻幻想、奇幻徽章
```

英文关键词：

```text
magical, fantasy, enchanted, moon and stars, elegant line art, mystical forest, soft glow, whimsical, fairy tale, dreamy
```

适合行业：

- 咖啡
- 香薰
- 文创
- 甜品
- 手作品牌
- 女性向品牌

## 6.3 现代风

中文关键词：

```text
现代、简洁、几何、留白、干净、品牌感、高级、克制、精致、符号化、极简
```

英文关键词：

```text
modern minimal, clean vector logo, geometric, balanced spacing, refined curves, premium brand identity, minimalist, simple, polished
```

适合行业：

- 科技
- 咖啡
- 设计工作室
- 咨询公司
- App 图标
- 个人品牌

## 6.4 餐饮风

中文关键词：

```text
有食欲、亲切、门店感、外卖头像、粗体字、醒目、暖色、烟火气、可爱吉祥物、品牌招牌
```

英文关键词：

```text
food logo, appetizing, bold Chinese typography, mascot logo, warm color palette, storefront branding, restaurant logo, takeout avatar
```

适合行业：

- 小吃
- 烤肉
- 焖饭
- 炸鸡
- 烘焙
- 快餐

## 6.5 复古徽章风

中文关键词：

```text
复古、徽章、圆形印章、咖啡馆、手作感、经典、轻怀旧、棕色线条、品牌章
```

英文关键词：

```text
vintage badge, retro logo, circular emblem, coffee badge, hand-crafted, classic, nostalgic, stamp logo
```

## 6.6 高级简约风

中文关键词：

```text
高级、克制、极简、优雅、留白、精致、轻奢、品牌识别、黑白、金色点缀
```

英文关键词：

```text
premium, elegant, minimal, refined, luxury, clean spacing, restrained, monochrome, gold accent
```
