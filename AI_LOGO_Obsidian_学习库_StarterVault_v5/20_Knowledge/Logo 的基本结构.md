# Logo 的基本结构

一个完整 Logo 通常由三部分组成：

## 3.1 图形标志

图形标志就是 Logo 的核心图案。

常见类型：

- 吉祥物头像
- 动物图形
- 食物图形
- 抽象字母
- 几何图形
- 圆形徽章
- 线性图标
- 组合图形

设计标准：

- 一眼能记住
- 缩小后还能看清
- 大形明确
- 不依赖过多细节
- 适合黑白版本

例子：

- 熊猫头 + 竹子 + 中文品牌名
- 圆形徽章 + 咖啡豆 + 森林元素
- 小人头像 + 厨师帽 + 餐饮品牌名
- 字母变形 + 渐变图形

## 3.2 字体标志

字体标志就是品牌名字的视觉表达。

字体不是随便打字，而是要和图形风格统一。

| 风格 | 字体方向 |
|---|---|
| 可爱风 | 圆角、粗体、柔和、膨胀感 |
| 魔幻风 | 优雅、弧线、装饰性、星星月亮元素 |
| 现代风 | 简洁、留白多、线条干净 |
| 餐饮风 | 粗壮、有食欲、亲切、易识别 |
| 潮牌风 | 强对比、硬朗、街头感 |
| 高级风 | 克制、细节少、比例稳定 |

## 3.3 辅助元素

辅助元素用于强化品牌气质。

常见辅助元素：

- 圆环
- 星星
- 咖啡豆
- 叶子
- 爱心
- 竹叶
- 小爪印
- 装饰线
- 月亮
- 蒸汽
- 几何点线

使用原则：

- 不能乱加
- 不能抢主体
- 必须服务品牌气质
- 数量要克制
- 缩小后不能造成脏乱
