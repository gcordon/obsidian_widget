## 按 Logo 类型查看

| Logo 类型 | 训练重点 | 以后能帮你做什么 |
|---|---|---|
| 外卖头像 | 缩小识别、强轮廓、少细节 | 练直接生成和局部修改 |
| 餐饮吉祥物 | 表情、比例、亲和力 | 练多方向生成和细节控制 |
| 圆形徽章 | 外圈文字、中心图形、复古感 | 练参考图分析和变体 |
| 门店招牌 | 横版构图、远距离可读 | 练文字、构图和可读性 |
| 包装贴纸 | 简洁图形、贴纸边界、品牌感 | 练应用场景和简化 |

## 按学习状态查看

| 状态 | 含义 | 下一步 |
|---|---|---|
| practice | 练习中 | 补图片、Prompt、评分 |
| case | 已形成案例 | 提炼可复用结构 |
| selected | 作品精选 | 加 mockup、变体和复盘说明 |
| ready-to-reuse | 方法可复用 | 补使用条件和失败点 |

## 每个案例必须回答

- 这个案例练了什么能力？
- 这个案例练的是哪一种 AI Logo 方法？
- 餐饮细分是什么？
- Logo 类型是什么？
- 哪个 Prompt 有效？
- 哪个问题最影响真实使用？
- 有什么可复用结构？
- 是否值得进入个人作品精选？
- 下一步要补什么？

## 案例命名建议

```text
案例 - 品牌名 - 餐饮细分 - Logo类型.md
```

例子：

```text
案例 - 食艺焖味 - 小吃快餐 - 吉祥物头像.md

```

## 如何从案例提炼方法

```text
案例复盘
→ 找出稳定 Prompt
→ 总结可复用构图
→ 判断适合哪个餐饮细分
→ 加入 Prompt 方法库或问题总结
→ 每周复盘推进
```
