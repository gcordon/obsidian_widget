# 图片案例记录规范

每个 Logo 练习都应该记录为一篇案例，而不是只保存图片。

## 推荐文件名

```text
案例 - 品牌名 - 练习主题.md
```

例子：

```text
案例 - 食艺焖味 - 高清复原.md
案例 - Forest Coffee - 魔幻徽章风.md
案例 - 猫熊设计 - 吉祥物头像.md
```

## 记录原则

- 不要只记录成功图，也要记录失败图和问题。
- Prompt 必须保存，方便复用和改进。
- 每次都要打分，否则无法判断进步。
- 最终图要尽量配套保存 SVG / PDF / AI。
