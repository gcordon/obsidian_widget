# Demo - 食艺焖味餐饮 Logo 复盘

## 基本信息

- 品牌名称：食艺焖味
- 行业：餐饮 / 焖饭 / 烤肉饭
- 目标风格：可爱、亲切、有食欲、适合外卖头像
- 使用工具：ChatGPT 网页版 / Obsidian / 后续可用 Figma 或 Illustrator
- 输出格式：PNG 初稿，后续建议 SVG / PDF

## 参考图

![[80_Assets/01_References/demo_食艺焖味_reference.svg]]

## 第一次 Prompt

```text
参考这张餐饮品牌 Logo，将它高清重绘为专业餐饮吉祥物 Logo。
品牌名称是「食艺焖味」。
保留圆形黄色头像、可爱小人、厨师帽、中文品牌名。
要求线条干净、边缘清晰、字体可读、颜色保持黄色黑色为主。
整体适合外卖头像和门店招牌。
不要复杂背景，不要水印，输出高清 PNG。
```

## 第一次结果

![[80_Assets/02_Generated/demo_食艺焖味_generated_v01.svg]]

## 发现的问题

- 文字：中文在 AI 生成时可能不稳定，建议后期人工重排。
- 构图：圆形头像方向正确，但面部细节可以继续简化。
- 颜色：黄色、黑色、白色统一，适合餐饮。
- 细节：小尺寸下应减少装饰。
- 是否像 Logo：整体像 Logo，不像复杂插画。

## 修改 Prompt

```text
请继续简化这张餐饮吉祥物 Logo。
保留圆形黄色头像和中文品牌名「食艺焖味」，减少面部小细节，线条更粗，整体更适合 64×64 外卖头像。
背景保持简洁，颜色控制在黄色、黑色、白色三种。
```

## 质量评分

| 项目 | 分数 | 备注 |
|---|---:|---|
| 缩小识别度 | 4 | 大形清楚，适合头像 |
| 文字准确度 | 3 | 文字建议后期人工校正 |
| 风格统一性 | 4 | 图形、配色、行业气质统一 |
| 品牌感 | 4 | 亲切、有食欲、适合餐饮 |
| 可矢量化程度 | 3 | 可矢量化，但需要简化细节 |
| 应用场景适配 | 4 | 适合头像、招牌、包装贴纸 |

## 我学到了什么

餐饮吉祥物 Logo 不要追求复杂角色，最重要的是头像识别度、配色记忆点和文字可读性。

## 下次改进

- 生成无字版图形标志。
- 单独设计中文字体。
- 做黑白版和反白版。
- 转 SVG 后检查路径是否干净。
