# 每天从这里开始：AI Logo 方法练习工作台

> 这个页面是日常唯一入口。目标不是看完整个 vault，也不是先研究怎么赚钱，而是每天练熟一种 AI Logo 生成或修改方法，并留下能复用的 Prompt、图片和总结。

## 今天只做这 3 件事

1. 选一种 AI Logo 生成方法。
2. 用对应 Prompt 在 ChatGPT 生成或修改 Logo。
3. 写一篇短记录，并回到 [[学习进度与任务追踪]] 打勾。

## 今天先选一种方法

刚开始按顺序练，不要每天跳太散：

| 顺序 | 方法 | 今天练什么 |
|---|---|---|
| 1 | 直接生成 Logo | 从品牌名、行业、用途直接生成初稿 |
| 2 | 参考图分析 | 上传参考图，拆解构图、颜色、字体、风格 |
| 3 | 多方向生成 | 同一需求生成 3 个不同方向并比较 |
| 4 | 局部修改 | 只改文字、颜色、主体、边框或构图 |
| 5 | 参考图生成变体 | 借鉴结构或风格，但换成新品牌 |
| 6 | 上传旧图修改 | 改清晰、改风格、改颜色或简化旧 Logo |
| 7 | 高清复原 | 把模糊、压缩、锯齿 Logo 复原清楚 |
| 8 | 矢量化准备 | 判断图形、线条、颜色是否适合 SVG / PDF / AI |

## 练完必须留下

每次练习至少留下 5 个东西：

- 今天练的方法。

- 一个完整 Prompt。
- 一篇 Daily Note。
- 一个问题总结和下次改法。

## 如果是别人让你做 Logo

不要直接开始生成图。先用 [[Logo 需求记录模板]] 记录：

- 对方要用在哪里。
- 想要和不想要的风格。
- 是否有参考图。
- 品牌名和文字是否最终确定。
- 是否需要 PNG 之外的 SVG / PDF / AI / EPS。

记录清楚后，再进入 Prompt、图片生成、案例复盘和作品精选。

## 结果评分

用这 6 项快速评分。评分不是为了完美，而是为了知道下次怎么改：

| 检查项 | 问题 |
|---|---|
| 缩小识别 | 64x64 外卖头像还清楚吗？ |
| 文字稳定 | 中文品牌名是否正确、可读？ |
| 餐饮感 | 一眼能看出行业和食欲吗？ |
| 风格统一 | 图形、字体、颜色是否一致？ |
| 可矢量化 | 线条和形状是否容易转 SVG？ |
| 可模板化 | 换品牌名和细分行业后还能复用吗？ |
