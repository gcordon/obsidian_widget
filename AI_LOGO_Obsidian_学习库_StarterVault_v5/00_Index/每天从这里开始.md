# 每天从这里开始

> 这是你每天学习 AI Logo / 图片设计时的入口。不要每天重新整理整个 Vault，只需要按流程完成一次练习、一次记录、一次复盘。

## 今日 15 分钟最低动作

1. 打开 [[AI Logo 学习 Dashboard]]。
2. 看 [[30 天练习计划]] 中今天对应的练习方向。
3. 在 ChatGPT 网页版上传参考图或生成图。
4. 使用 [[每日图片练习启动 Prompt]] 开始练习。
5. 练习结束后使用 [[练习结束导出 Obsidian Markdown Prompt]]。
6. 把图片保存到 `80_Assets/` 对应目录。
7. 把 Markdown 放进 `00_Inbox/` 或 `01_Daily/`。
8. 每 2-3 天让 Codex 按 [[Codex 每日与每周整理 Prompt]] 整理一次。

## 三个工具的角色

| 工具 | 角色 | 你每天怎么用 |
|---|---|---|
| ChatGPT 网页版 / Project | 图片教练与图片创作工具 | 看图、生成图、改图、评分、输出 Markdown |
| Obsidian | 长期知识库 | 保存 Prompt、案例、图片链接、复盘、作品集 |
| Codex | 本地整理员 | 移动文件、补链接、提取 Prompt、生成周复盘、检查断链 |

## 今天结束前必须留下的东西

每次练习结束，至少留下：

- 一张参考图或生成图；
- 一段最终可复用 Prompt；
- 一篇 Daily Note；
- 一篇案例复盘草稿；
- 一条“下次要改进什么”。

## 不要每天做的事

- 不要每天上传整个 zip 给 ChatGPT。
- 不要每天下载新 zip 覆盖本地 Obsidian。
- 不要让 Codex 一次性重构整个 vault。
- 不要只保存图片，不写 Prompt 和复盘。

## 推荐节奏

```text
每天：ChatGPT 生图 / 改图 + 输出 Obsidian Markdown
每 2-3 天：Codex 本地整理 00_Inbox 和 01_Daily
每周：Codex 生成周复盘 + 检查图片链接 + 更新作品集
每月：打包 zip 给 GPT 做一次大检查或大版本更新
```
