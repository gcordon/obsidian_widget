# 每天从这里开始：餐饮 Logo 学习工作台

> 这个页面是日常唯一入口。目标不是看完整个 vault，而是完成一次 AI 餐饮 Logo 练习，并留下能变成案例、Prompt 或待售资产的内容。

## 今天只做这 3 件事

1. 选一个餐饮细分和 Logo 类型。
2. 用一个 Prompt 生成或改进 Logo。
3. 写一篇短记录，并判断是否进入案例或资产候选。

## 本周餐饮 Logo 方向

优先从这 5 个方向里选一个，不要每天换太散：

| 方向 | 适合练什么 | 资产潜力 |
|---|---|---|
| 外卖头像 Logo | 缩小识别、强对比、图形简化 | 外卖头像模板包 |
| 餐饮吉祥物 Logo | 角色比例、表情、亲和力 | 吉祥物 Logo 模板包 |
| 圆形徽章 Logo | 外圈文字、中心图形、复古结构 | 徽章 Logo 模板包 |
| 咖啡 / 奶茶 Logo | 简洁高级、品牌氛围、包装延展 | 咖啡奶茶品牌包 |
| 门店招牌 Logo | 横版构图、招牌可读性、mockup | 门头招牌模板包 |

## 今天复制这个 Prompt

先用这个通用启动 Prompt，练完再进入更细分模板：

```text
我今天要练习一个餐饮 Logo。

餐饮细分：[小吃 / 奶茶 / 咖啡 / 烧烤 / 甜品 / 快餐 / 地方菜]
Logo 类型：[外卖头像 / 吉祥物 / 圆形徽章 / 门店招牌 / 包装贴纸]
品牌名称：[填写品牌名]
目标风格：[可爱 / 现代 / 复古 / 高级简约 / 烟火气 / 国潮]

请先帮我分析这个 Logo 方向应该注意什么：
1. 核心图形应该是什么；
2. 字体和文字如何避免 AI 出错；
3. 配色应该怎么控制；
4. 小尺寸头像是否清楚；
5. 这个方向是否适合做成模板包。

然后给我一个可直接用于生成图片的 Prompt。
```

## 练完必须留下

每次练习至少留下 5 个东西：

- 一张参考图或生成图。
- 一个最终可复用 Prompt。
- 一篇 Daily Note。
- 一个问题总结。
- 一个商业化判断：是否可能进入模板包。

## 结果评分

用这 6 项快速评分：

| 检查项 | 问题 |
|---|---|
| 缩小识别 | 64x64 外卖头像还清楚吗？ |
| 文字稳定 | 中文品牌名是否正确、可读？ |
| 餐饮感 | 一眼能看出行业和食欲吗？ |
| 风格统一 | 图形、字体、颜色是否一致？ |
| 可矢量化 | 线条和形状是否容易转 SVG？ |
| 可模板化 | 换品牌名和细分行业后还能复用吗？ |
