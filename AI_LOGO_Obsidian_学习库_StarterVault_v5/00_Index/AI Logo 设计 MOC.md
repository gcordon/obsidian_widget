# AI Logo 学习与资产地图

> 这不是每日入口。每日学习从 [[每天从这里开始]] 进入。本页只负责说明整个 vault 的结构，以及每个区域如何服务「AI 餐饮 Logo 学习 → 可售卖资产」。

## 核心闭环

```text
学习餐饮 Logo 判断标准
→ 每日练习
→ 保存图片和 Prompt
→ 案例复盘
→ 提炼稳定 Prompt
→ 进入待售资产候选
→ 每周复盘
```
