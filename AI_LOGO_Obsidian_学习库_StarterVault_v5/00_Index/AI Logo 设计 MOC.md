# AI Logo 学习与方法地图

> 这不是每日入口。每日学习从 [[每天从这里开始]] 进入。本页只负责说明整个 vault 的结构，以及每个区域如何服务「AI Logo 生成方法训练 → Prompt 和案例沉淀」。

## 核心闭环

```text
选择一种 AI Logo 生成方法
→ 在 ChatGPT 生成、分析或修改
→ 保存图片和 Prompt
→ 写 Daily
→ 案例复盘
→ 提炼稳定 Prompt
→ 总结方法、问题和常见错误
→ 每周复盘
```
