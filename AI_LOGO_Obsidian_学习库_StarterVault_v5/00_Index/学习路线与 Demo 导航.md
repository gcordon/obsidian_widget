# 第一次打开先走这里

> 目标不是读完所有资料，而是在第一次使用时完成一个最小闭环：看 Demo、复制 Prompt、做一次练习、写一篇记录、知道如何沉淀案例。

## 只走 5 步

1. 打开 [[每天从这里开始]]，理解日常工作台。
2. 看 [[Demo - 一次完整学习流]]，知道完整流程长什么样。
3. 看 [[Demo - 食艺焖味餐饮 Logo 复盘]]，理解餐饮 Logo 案例怎么复盘。
4. 复制 [[每日图片练习启动 Prompt]]，在 ChatGPT 开始一次餐饮 Logo 练习。
5. 用 [[ChatGPT 每日练习记录模板]] 写一篇 Daily。

## 第一次练习推荐题目

不要从复杂品牌开始。任选一个：

| 题目 | 品牌名示例 | Logo 类型 | 练习重点 |
|---|---|---|---|
| 外卖头像 | 食艺焖味 | 餐饮吉祥物 | 缩小识别、中文稳定 |
| 咖啡徽章 | FOREST COFFEE | 圆形徽章 | 外圈文字、中心图形 |
| 奶茶门店 | 茶小满 | 门店招牌 | 横版构图、招牌可读 |

## 第一次练习 Prompt

```text
我想做一次 AI 餐饮 Logo 练习。

品牌名称：[填写]
餐饮细分：[小吃 / 奶茶 / 咖啡]
Logo 类型：[外卖头像 / 吉祥物 / 圆形徽章 / 门店招牌]
目标风格：[可爱 / 现代 / 复古 / 高级简约]

请先告诉我这个方向的 Logo 应该注意什么，再给我一个可直接用于图片生成的 Prompt。
最后请告诉我练完后应该记录哪些内容，方便整理到 Obsidian。
```

## 练完以后怎么整理

最小整理顺序：

```text
图片放入 80_Assets/
→ Daily 放入 01_Daily/
→ 有价值内容进入 40_Cases/
→ 稳定 Prompt 进入 30_Prompts/
→ 接近商业可用的结果进入 60_Portfolio/
```

## 新手只需要记住

- ChatGPT 负责看图、做图、改图、评分。
- Obsidian 负责长期记录。
- Codex 负责整理 Markdown、链接、Prompt、复盘。
- 每次练习都要问：这能不能变成未来可售卖资产？
