# 2026-05-26 项目目标与改造共识

## 这次讨论的核心结论

项目目标不是单纯学习 AI Logo，也不是为了整理复杂文档。

真正目标是：

```text
用 AI 学习和制作餐饮 Logo
→ 通过记录和复盘提升技能
→ 把练习沉淀为案例、Prompt、风格规律和模板结构
→ 长期形成可售卖资产
→ 用赚钱目标维持学习动力
```

第一条长期商业主线是：

```text
餐饮 Logo 模板包 / Prompt 包 / 风格包 / 素材包
```

## 为什么选择餐饮 Logo

用户确认长期方向为模板 / 素材包，而不是优先接单。

餐饮 Logo 适合作为第一条商业主线，因为：

- 需求高，适合小商家、外卖店、咖啡店、奶茶店、小吃店。
- 类型明确，容易做成系列：外卖头像、吉祥物、圆形徽章、门店招牌、包装贴纸。
- AI 出图适合快速探索风格。
- 通过大量案例可以沉淀稳定 Prompt 和模板结构。
- 未来可发展为 Prompt 包、模板包、风格包、素材包。

## 项目应当变成什么

新的定位：

```text
AI 餐饮 Logo 商业学习系统
```

不是：

- 普通知识库
- 单纯 Prompt 收藏夹
- 普通作品集
- 复杂项目管理系统

而是：

- 每天能开始练习的工作台
- 能记录练习过程的 Daily 系统
- 能总结能力提升的案例库
- 能提炼稳定指令的 Prompt 包
- 能判断商业价值的待售资产库
- 能每周推进资产化的复盘系统

## 当前已确认的学习闭环

```text
每日餐饮 Logo 练习
→ 保存图片和 Prompt
→ 写 Daily
→ 整理案例复盘
→ 提炼可复用 Prompt
→ 标记待售资产候选
→ 每周商业复盘
```

每次练习至少要留下：

- 图片或图片路径
- 使用 Prompt
- 结果评分
- 今天学到什么
- 可复用点
- 是否能进入案例 / Prompt 包 / 资产候选

## 当前已确认的商业资产方向

优先沉淀 5 类餐饮 Logo 资产：

1. 外卖头像 Logo 模板包
2. 餐饮吉祥物 Logo 模板包
3. 圆形徽章 Logo 模板包
4. 咖啡 / 奶茶 Logo 模板包
5. 门店招牌 Logo 模板包

每类资产都要逐步补齐：

- 案例
- Prompt
- 图片
- mockup
- 质量评分
- 常见错误
- 使用说明
- 缺失内容
- 是否可售卖判断

## 后续 AI 每次进入项目要做什么

进入项目后先读取：

1. 本文件
2. [[每天从这里开始]]
3. [[AI Logo 设计 MOC]]
4. [[Vault 体检报告]]

然后判断用户任务属于哪类：

| 用户任务 | 优先处理 |
|---|---|
| 整理今天练习 | Daily → 案例 → Prompt → 资产候选 |
| 检查 Logo | 使用 [[Logo 质量检查表]] 和商业可用性标准 |
| 生成周复盘 | 总结技能进步、稳定 Prompt、资产进度 |
| 整理 Prompt | 按餐饮细分、Logo 类型、稳定性整理 |
| 整理作品集 | 优先更新待售资产候选 |
| 改造结构 | 不能破坏每日学习闭环 |

## 重要约束

- 不自动 commit，除非用户明确要求。
- 不要为了结构好看而让学习更难。
- 不要编造练习结果或案例成果。
- 不要把还没验证的 Prompt 写成已稳定。
- 不要把 PNG 说成可编辑 AI 文件。
- 图片生成、看图和局部修改优先交给 ChatGPT 网页版；Codex 主要负责整理和复盘。
