# 2026-05-26 项目目标与改造共识

## 当前最新共识

本项目当前主线已经修正为：

```text
AI Logo 生成方法训练
→ 直接生成
→ 参考图分析
→ 参考图变体
→ 上传旧图修改
→ 局部修改
→ 多方向生成
→ 高清复原
→ 矢量化准备
→ Prompt、图片、问题和复盘沉淀
```

当前阶段不是研究怎么赚钱，也不是卖 Prompt 包、模板包、风格包或素材包。赚钱是长期背景，后续可以研究；现在先把 AI 生成 Logo 的方法练熟。

## 为什么仍然用餐饮 Logo 练习

餐饮 Logo 继续作为第一条练习主题，因为：

- 场景真实，外卖头像、门店招牌、包装贴纸都容易理解。
- 类型明确，适合反复练：吉祥物、圆形徽章、头像、招牌、包装。
- AI 出图适合快速试方向。
- 很容易暴露常见问题：文字错误、细节过多、缩小不清楚、风格不统一。

但餐饮不是最终限制。它只是当前阶段的训练题材。

## 项目应当变成什么

新的定位：

```text
AI Logo 生成方法训练系统
```

不是：

- 普通知识库
- 单纯 Prompt 收藏夹
- 复杂项目管理系统
- 接单赚钱研究库
- 卖 Prompt 包或模板包的资料库

而是：

- 每天能开始练一种方法的工作台
- 能记录练习过程的 Daily 系统
- 能追踪每种方法是否练过的进度表
- 能总结 Prompt、问题和改法的方法库
- 能复盘真实生成结果的案例库

## 当前必须练的 8 种方法

| 方法 | 练习重点 |
|---|---|
| 直接生成 Logo | 从文字需求直接生成初稿 |
| 参考图分析 | 拆解构图、颜色、字体、风格 |
| 参考图生成变体 | 学习参考图语言，但不照抄 |
| 上传旧图修改 | 改清晰、改颜色、改风格、简化旧图 |
| 局部修改 | 只改文字、颜色、主体、边框等局部 |
| 多方向生成 | 一次探索 3 个方向并选择继续迭代 |
| 高清复原 | 把模糊 Logo 变清晰 |
| 矢量化准备 | 判断是否适合 SVG / PDF / AI |

## 当前学习闭环

```text
打开 [[START_HERE_每天从这里开始]]
→ 查看 [[学习进度与任务追踪]]
→ 选择一种方法
→ 打开 [[Prompt 模板库]]
→ 在 ChatGPT 生成、分析或修改 Logo
→ 保存图片到 80_Assets/
→ 用 [[ChatGPT 每日练习记录模板]] 写 Daily
→ 回到进度表打勾
→ 有价值再进入案例库或 Prompt 方法库
```

每次练习至少留下：

- 今日练习方法
- 使用 Prompt
- 图片路径
- 结果问题
- 下次改法

## 后续 AI 每次进入项目要做什么

进入项目后先读取：

1. [[START_HERE_每天从这里开始]]
2. [[学习进度与任务追踪]]
3. 本文件
4. [[AI Logo 生成方法训练地图]]
5. [[每天从这里开始]]

然后判断用户任务属于哪类：

| 用户任务 | 优先处理 |
|---|---|
| 刚开始学习 | 指向 [[每天从这里开始]]，先选一种方法 |
| 整理今天练习 | Daily → 方法判断 → Prompt → 案例 |
| 检查 Logo | 使用 [[Logo 质量检查表]] |
| 整理 Prompt | 先按方法分类，再按 Logo 类型细分 |
| 生成周复盘 | 总结本周练过的方法、稳定 Prompt、反复问题 |
| 记录 Logo 需求 | 使用 [[Logo 需求记录模板]]，但不让需求记录抢占当前学习主线 |
| 改造结构 | 不能破坏每日方法练习闭环 |

## 重要约束

- 不自动 commit，除非用户明确要求。
- 当前不研究赚钱路径，除非用户明确再次要求。
- 不要把项目改回「卖模板包 / Prompt 包 / 素材包」。
- 不要为了结构好看而让学习更难。
- 不要编造练习结果或案例成果。
- 不要把还没验证的 Prompt 写成已稳定。
- 不要把 PNG 说成可编辑 AI 文件。
- 图片生成、看图和局部修改优先交给 ChatGPT 网页版；Codex 主要负责整理和复盘。
