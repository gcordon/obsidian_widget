# 图片链接

Obsidian 中嵌入图片通常使用：

```md
![[80_Assets/03_Final/文件名.png]]
```

本库建议所有图片都放在 `80_Assets/` 中：

- `80_Assets/01_References/`：参考图
- `80_Assets/02_Generated/`：生成过程图
- `80_Assets/03_Final/`：最终图
- `80_Assets/04_SVG_AI_PDF/`：SVG / AI / PDF / EPS
- `80_Assets/05_Mockups/`：应用场景图
