# 2. AI Logo 设计基础认知

AI 做 Logo，不是简单生成一张好看的图。

真正可用的 Logo 需要满足：

- 识别度高
- 结构简单
- 可缩放
- 可复用
- 能表达品牌气质
- 适合后期编辑
- 适合不同场景应用

很多 AI 图看起来很好看，但可能存在这些问题：

1. 细节太多，缩小到头像或包装贴纸时看不清。
2. 文字不稳定，容易写错字、漏字、变形。
3. 不是矢量图，后期不好编辑。
4. 更像插画，不像 Logo。
5. 缺少品牌统一性，单张图好看，但做菜单、包装、招牌时不成体系。

正确目标：

> 用 AI 快速探索风格和创意，再用矢量工具整理成真正可用的 Logo。

# 3. Logo 的基本结构

一个完整 Logo 通常由三部分组成：

## 3.1 图形标志

图形标志就是 Logo 的核心图案。

常见类型：

- 吉祥物头像
- 动物图形
- 食物图形
- 抽象字母
- 几何图形
- 圆形徽章
- 线性图标
- 组合图形

设计标准：

- 一眼能记住
- 缩小后还能看清
- 大形明确
- 不依赖过多细节
- 适合黑白版本

例子：

- 熊猫头 + 竹子 + 中文品牌名
- 圆形徽章 + 咖啡豆 + 森林元素
- 小人头像 + 厨师帽 + 餐饮品牌名
- 字母变形 + 渐变图形

## 3.2 字体标志

字体标志就是品牌名字的视觉表达。

字体不是随便打字，而是要和图形风格统一。

| 风格 | 字体方向 |
|---|---|
| 可爱风 | 圆角、粗体、柔和、膨胀感 |
| 魔幻风 | 优雅、弧线、装饰性、星星月亮元素 |
| 现代风 | 简洁、留白多、线条干净 |
| 餐饮风 | 粗壮、有食欲、亲切、易识别 |
| 潮牌风 | 强对比、硬朗、街头感 |
| 高级风 | 克制、细节少、比例稳定 |

## 3.3 辅助元素

辅助元素用于强化品牌气质。

常见辅助元素：

- 圆环
- 星星
- 咖啡豆
- 叶子
- 爱心
- 竹叶
- 小爪印
- 装饰线
- 月亮
- 蒸汽
- 几何点线

使用原则：

- 不能乱加
- 不能抢主体
- 必须服务品牌气质
- 数量要克制
- 缩小后不能造成脏乱

# 4. AI Logo 标准流程

## 第一步：明确品牌定位

每次开始之前，先回答这些问题：

1. 品牌叫什么？
2. 做什么行业？
3. 面向什么人群？
4. 想要什么感觉？
5. 用在什么地方？
6. 是否需要中文？
7. 是否需要英文？
8. 是否要做成可编辑矢量？

示例：

```text
品牌名：食艺焖味
行业：餐饮 / 焖饭 / 烤肉芝士饭
风格：可爱、亲切、干净、有食欲
用途：门店招牌、外卖头像、包装贴纸、小程序头像
输出：高清 PNG + 后续 SVG
```

## 第二步：找参考图

参考图不是为了照抄，而是为了分析：

- 构图
- 颜色
- 字体
- 线条
- 图形比例
- 品牌气质
- 使用场景

分析模板：

```text
参考图名称：
核心构图：
主要颜色：
图形元素：
字体风格：
辅助元素：
我想保留的部分：
我想改变的部分：
```

## 第三步：让 AI 先出风格方案

不要一开始追求最终稿。先让 AI 出 3 到 6 个方向。

常见方向：

- 可爱型
- 魔幻型
- 现代型
- 复古型
- 高级简约型
- 潮牌插画型
- 餐饮吉祥物型
- 圆形徽章型

## 第四步：选择方向继续深化

检查问题：

- 文字有没有错？
- 图形是否太复杂？
- 线条是否清楚？
- 颜色是否统一？
- 缩小后还能不能看？
- 有没有多余元素？
- 是否像 Logo，而不是插画？
- 是否适合转 SVG？

## 第五步：转成可编辑文件

AI 默认生成的是 PNG，它只是位图。

真正可编辑的 Logo 通常需要：

- SVG
- PDF
- AI
- EPS

推荐流程：

```text
AI 生成高清 PNG
↓
挑选最佳方案
↓
矢量化为 SVG
↓
在 Illustrator / Figma / Boxy SVG 中编辑
↓
导出 AI / PDF / SVG / PNG
```

注意：

> 如果只是把 PNG 放进 AI 文件里，它仍然不是可编辑 Logo。真正重要的是图形是否由可编辑路径组成。

# 9. AI Logo 常见错误

## 9.1 字体错误

AI 容易把中文、英文、数字写错。

解决方法：

- Prompt 中明确写出文字
- 要求不要添加额外文字
- 后期用 Illustrator / Figma 重新排文字
- 文字复杂时，先生成无字图形，再单独加字

## 9.2 细节过多

问题表现：

- 毛发太多
- 阴影太多
- 叶子太多
- 星星太多
- 渐变太复杂
- 小尺寸看起来脏

解决方法：

- 要求「logo-like, simple, clean vector」
- 控制装饰元素数量
- 强调「大形清楚，小细节少」

## 9.3 风格不统一

比如：

- 图形是可爱风，字体是科技风
- 主体是复古风，配色是霓虹科技风
- 吉祥物很软萌，文字很硬朗

解决方法：

- 在 Prompt 中同时描述图形和字体风格
- 使用统一的关键词
- 生成后检查字体与图形是否协调

## 9.4 只是插画，不是 Logo

插画可以有场景、有复杂光影、有很多细节。  
Logo 应该更像一个符号。

解决方法：

Prompt 中加入：

```text
logo design, clean vector logo, simple symbol, brand mark, not illustration, no complex background
```

## 9.5 不能编辑

只拿 PNG 不够。

最终建议至少保留：

- 高清 PNG
- SVG
- PDF
- AI 或 EPS

# 11. 30 天练习计划

## 第 1 周：Logo 结构分析

## 第 2 周：风格替换练习

目标：同一个 Logo 做不同风格。

每天选择一个参考图，生成 3 个方向：

- 可爱风
- 现代风
- 魔幻风

复盘问题：

- 哪个方向最适合品牌？
- 哪个方向最容易落地？
- 哪个方向文字最稳定？
- 哪个方向最容易转 SVG？

## 第 3 周：高清复原练习

目标：练习模糊图高清重绘。

每天选择一张模糊 Logo：

- 保持原构图
- 修复线条
- 重建文字
- 清理背景
- 输出高清 PNG

复盘问题：

- 是否过度改变原图？
- 字体是否还原？
- 主体是否更清晰？
- 是否适合继续矢量化？

## 第 4 周：矢量化与品牌延展

目标：把 Logo 做成真正的品牌资产。

每天选一张图做其中一项：

- SVG 可编辑版
- 黑白版
- 圆形头像版
- 横版 Logo
- 竖版 Logo
- 包装贴纸版
- 门店招牌效果图
- 外卖平台头像版

最终输出：

- 3 个完整案例
- 1 个作品集页面
- 1 套常用 Prompt 模板
- 1 套自己的风格词库

# 12. SVG / AI / PDF 工作流

## 12.1 推荐格式

| 格式 | 用途 |
|---|---|
| PNG | 预览、展示、头像 |
| SVG | 可编辑矢量、网页、图标 |
| PDF | 印刷、交付、Illustrator 打开 |
| AI | Illustrator 原生编辑 |
| EPS | 传统印刷和 Logo 交付 |

## 12.2 推荐流程

```text
生成 PNG
↓
选中最佳方案
↓
矢量化为 SVG
↓
打开 SVG 编辑
↓
修文字、修路径、修颜色
↓
导出 AI / PDF / SVG / PNG
```

## 12.3 在线编辑工具

| 工具 | 地址 | 适合用途 |
|---|---|---|
| Boxy SVG | https://boxy-svg.com/app | 直接编辑 SVG，适合 Logo 路径和渐变 |
| Figma | https://www.figma.com | 排版、品牌系统、组件化设计 |
| Vectorpea | https://www.vectorpea.com/ | 在线编辑 SVG / PDF / AI 类文件 |
| Vectr | https://vectr.com/ | 简单图形和基础 Logo 编辑 |
| SVGator | https://www.svgator.com/create-svg | SVG 编辑和动画 |
| Method Draw | https://editor.method.ac/ | 免费简单 SVG 编辑 |
| SVG Viewer | https://www.svgviewer.dev/ | 查看、优化、微调 SVG |

## 12.4 注意事项

- AI 文件后缀不等于真正可编辑。
- 如果 AI 文件里只有一张 PNG，那仍然不能改路径。
- 真正可编辑的 Logo 应该由路径、形状、文字、图层组成。
- 最稳的方式是先做 SVG，再用 Illustrator 另存为 AI。

# 16. 关键原则总结

1. AI Logo 不是一次生成结束，而是一个设计流程。
2. 参考图用于分析结构，不是用于照抄。
3. 好 Logo 要能缩小、能黑白、能应用、能编辑。
4. 文字最好后期人工校正。
5. 颜色控制在 2 到 4 种更稳。
6. 图形要有大形，不要只靠细节。
7. 生成多个方向，再选一个深化。
8. PNG 适合预览，SVG / AI 才适合后期修改。
9. 每个案例都要复盘，否则不会持续提升。
10. 最终目标是建立自己的品牌设计判断力。

核心一句话：

> AI 负责快速给你大量视觉可能性，你负责判断哪个方向像品牌、能落地、能长期使用。
