# 80_Assets 图片素材区

这里用于保存所有图片和可交付文件。

## 文件夹说明

| 文件夹 | 用途 |
|---|---|
| `01_References` | 参考图、客户提供的旧 Logo、网上找的风格参考 |
| `02_Generated` | ChatGPT 生成过程图、不同版本草稿 |
| `03_Final` | 最终选定的 Logo PNG / JPG |
| `04_SVG_AI_PDF` | SVG、AI、PDF、EPS 等可编辑或交付文件 |
| `05_Mockups` | 招牌、包装、头像、名片、菜单等应用场景图 |

## 命名规则

```text
日期_品牌名_类型_版本.格式
```

例子：

```text
2026-05-25_食艺焖味_reference_01.png
2026-05-25_食艺焖味_generated_v01.png
2026-05-25_食艺焖味_final_logo.png
2026-05-25_食艺焖味_svg_v01.svg
2026-05-25_食艺焖味_mockup_packaging.png
```

## 注意事项

- 参考图和最终图分开放。
- 不要把所有图片直接扔进根目录。
- 最终图最好同时保存 PNG 和 SVG。
- 案例笔记中要用 `![[图片路径]]` 引用图片。
