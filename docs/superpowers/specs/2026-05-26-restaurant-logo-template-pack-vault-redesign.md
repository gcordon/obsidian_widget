# AI Logo 生成方法训练系统改造设计

日期：2026-05-26

## 核心目标

当前项目要从「AI 餐饮 Logo 学习与服务能力系统」进一步收窄为「AI Logo 生成方法训练系统」。

现阶段目标不是研究怎么赚钱，也不是卖 Prompt 包、模板包、风格包或素材包。当前最重要的是把 AI 生成 Logo 的不同方法学熟、练熟、记录清楚：

```text
直接生成
→ 参考图分析
→ 参考图变体
→ 上传旧图修改
→ 局部修改
→ 多方向生成
→ 高清复原
→ 矢量化与交付准备
→ Daily 记录
→ 案例复盘
→ Prompt 方法总结
```

长期背景可以保留：以后可能给别人做 Logo，并通过 Logo 服务赚钱。但这不是当前 vault 的日常主线。当前主线是技能学习、流程化练习、复盘总结和方便查看。

## 设计原则

1. 日常入口必须先回答「今天练哪一种 AI Logo 方法」。
2. 学习记录要围绕方法，而不是围绕赚钱、售卖资产或复杂项目管理。
3. Prompt 库按生成方法分类，方便复制和复用。
4. 进度追踪要能判断每种方法是否看过、练过、复盘过、初步掌握。
5. 餐饮 Logo 继续作为第一条练习主题，因为它场景清楚、类型明确、适合大量练习。
6. 真实需求和未来赚钱只作为长期背景，不抢占当前学习入口。
7. 不为了文档完整而增加负担；每天能开始练习比结构漂亮更重要。

## 当前要解决的问题

当前 vault 已经有入口页、Prompt、案例、作品集和复盘，但主线仍有几个问题：

- 目标里「给别人做 Logo / 服务能力」出现得偏早，容易让初学阶段分心。
- 入口页更像餐饮 Logo 练习入口，还不够像 AI 生成方法训练入口。
- 缺少一个专门说明「AI Logo 有哪些生成和改图方法」的地图。
- 学习进度表缺少方法维度，无法确认直接生成、改图、模仿风格等是否练过。
- Prompt 库偏按 Logo 类型和风格组织，需要增加按方法分类的使用顺序。

## 核心页面职责

### 根目录 START_HERE

职责：让用户第一次打开 vault 或不知道从哪里开始时，立即进入正确主线。

应该只强调：

```text
选一种 AI Logo 方法
→ 打开对应 Prompt
→ 在 ChatGPT 生成或修改 Logo
→ 保存图片
→ 写 5 行总结
→ 更新学习进度
```

### 每天从这里开始

职责：日常唯一工作台。

每日流程不再先问「今天练哪个商业方向」，而是先问：

```text
今天练哪一种 AI Logo 生成方法？
```

推荐方法：

- 直接生成 Logo
- 参考图分析
- 参考图生成变体
- 上传旧图修改
- 局部修改
- 多方向生成
- 高清复原
- 矢量化与交付准备

### AI Logo 生成方法训练地图

职责：解释每种方法练什么、何时用、产出什么、记录到哪里。

这是当前新增的核心地图，优先级高于作品集和未来服务流程。

职责：从「收藏 Prompt」变成「按方法训练 Prompt」。

分类：

- 01 直接生成 Prompt
- 02 参考图分析 Prompt
- 03 参考图变体 Prompt
- 04 上传旧图修改 Prompt

- 07 高清复原 Prompt

每个 Prompt 都要记录：

- 使用案例

## 非目标

当前不做：

- 不研究接单平台。
- 不把赚钱路径作为当前学习主线。
- 不卖 Prompt 包、模板包、风格包或素材包。
- 不引入复杂 Obsidian Bases 或 Canvas。
- 不把 vault 变成项目管理系统。
- 不强迫一次性看完整个 vault。
- 不把作品集当作当前第一重点。

## 验收标准

改造后，用户打开 Obsidian 应该能快速回答：

1. 今天从哪里开始。
2. 今天练哪一种 AI Logo 生成方法。
3. 用哪个 Prompt。
4. 图片保存在哪里。
5. 练完记录到哪里。
6. 哪些方法已经练过，哪些还没练。
7. 后续 AI 接手时是否知道当前目标是方法训练，而不是赚钱或卖资料包。
