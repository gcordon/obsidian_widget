# IMG-001：精确不变量偏差后继续全图生成修正

1. **适用：** 适用于要求从直接父资产精确继承画布、背景、有限调色板、整体前景边界、元素位置、尺寸或间距的图片任务。
2. **触发：** 当前生成稿任一精确不变量与直接父资产不一致。
3. **停止：** 立即停止使用全图生成修正精确不变量。
4. **禁止：** 适用条件未变化时，不得仅加强 Prompt 后重复相同全图生成路径。
5. **恢复：** 返回直接父资产，只在用户授权区域内执行局部编辑或确定性处理，并生成新文件或新版本。
6. **通过：** 可测量的精确不变量与直接父资产一致，且授权区域外无非预期变化。

## 证据

- [杨荣洋 Logo 生成记录](../../Logo案例/杨荣洋Logo/生成记录.md)：回放测试 v1、v2 连续违反背景、边界、尺寸和间距不变量；v3 通过确定性局部合成恢复并验证授权区域外差异为 `0`。
