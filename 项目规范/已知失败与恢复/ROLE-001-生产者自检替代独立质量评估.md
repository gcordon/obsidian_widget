# ROLE-001：生产者自检替代独立质量评估

1. **适用：** 适用于项目内形成修改方案、实验、候选成品或发布材料的任务。
2. **触发：** 生产者准备以自己的检查结果作为候选交付物的最终评估。
3. **停止：** 立即停止把生产者自检作为完成依据。
4. **禁止：** 不得以协调汇总、用户批准门或生产者补充说明替代独立质量评估。
5. **恢复：** 由未参与生产的质量与实验评估 Agent 按同一目标和验收标准独立输出 `Pass` 或 `Needs work`。
6. **通过：** 独立评估为 `Pass`，且项目协调 Agent 的完成闸门确认没有缺失角色。

## 证据

- [闲鱼与 GPT Image 2 项目角色体系](../../Agent角色管理/当前项目/闲鱼与GPT-Image-2角色体系.md)：2026-07-27 标题优化任务曾由协调 Agent 自检，缺失独立评估。
