# 资产溯源与派生血缘

## 目的

本规范是派生资产来源关系和变换事实的详细规则。根目录 `AGENTS.md` 只保留核心不变量和执行入口；案例 `生成记录.md` 是该案例实际事实的单一权威记录。

## 术语

1. 资产身份（Asset Identity）：由稳定路径、用途和内容 SHA-256 共同识别的资产版本。
2. 资产溯源（Asset Provenance）：单个资产的来源、形成过程和责任证据。
3. 资产血缘（Asset Lineage）：根权威参考经连续派生关系到当前输出的完整链路。
4. 根权威参考（Root Authoritative Reference）：控制来源身份和视觉语言的最初权威资产。
5. 直接父资产（Direct Parent Asset）：输出直接继承版式或内容的已有资产。
6. 直接输入资产（Direct Input Asset）：一次实际变换中提交给工具或参与本地处理的输入资产；数量为 `1..N`。
7. 派生关系（Derivation Relationship）：输入与输出之间的身份关系。
8. 变换记录（Transformation Record）：一次实际生成、编辑或后处理的事实记录。

## 派生关系

1. `复刻`：首次根据根权威参考还原同一个 Logo，输出仍代表同一 Logo 身份。
2. `二次开发`：继承已有资产的部分特征，并形成新文字、品牌、版式或用途资产。
3. `修正`：当前稿未达到确认目标时追加的新变换或新版本；它属于当前复刻或二次开发任务，不是并列任务模式。
4. 每条关系必须同时指明直接父资产和输出资产。
5. 同一变换存在多个实际输入时，必须逐一记录每个输入的角色。

## 权威关系

1. 根权威参考控制来源身份和视觉语言。
2. 直接父资产控制现有版式和可继承内容。
3. 用户确认的变更规格控制新内容和允许变化的范围。
4. 三者冲突时，不得自行选择；必须先让用户确认新的变更规格。
5. 根权威参考不等于每次工具调用的实际输入；未提交给工具的资产只记录为血缘权威，不列为直接输入。

## 记录结构

每个案例的 `生成记录.md` 按以下顺序记录，空缺历史字段使用 `未知（未保留）`，不得推测。

### 1. 任务身份

1. 记录顶层任务模式：`复刻` 或 `二次开发`。
2. 记录输出资产身份和用途。
3. 记录用户确认的变更规格入口或摘要。

### 2. 资产清单

每个资产版本记录以下字段：

| 字段 | 要求 |
|---|---|
| 资产角色 | 根权威参考、直接父资产、其他输入、中间结果或输出 |
| 稳定路径 | 仓库相对路径；未保留时写明未知 |
| 用途 | 该资产在链路中的职责 |
| 规格 | 像素尺寸、格式、背景/透明通道等必要属性 |
| SHA-256 | 对已保留文件必填；未保留时写明未知 |

### 3. 资产血缘

1. 使用一条从根权威参考到当前输出的有向链表达全局关系。
2. 为每条边标注 `复刻`、`二次开发` 或 `修正（所属模式）`。
3. 全局链只做导航；每次变换的完整事实保存在变换记录中。

### 4. 变换记录

每次实际变换追加一条记录，不覆盖旧记录。

| 字段 | 要求 |
|---|---|
| 变换身份 | 案例内唯一的阶段或版本名称 |
| 所属模式 | `复刻` 或 `二次开发` |
| 派生关系 | `复刻`、`二次开发` 或 `修正` |
| 直接输入 `1..N` | 实际参与本次工具调用或本地处理的资产及角色 |
| 直接父资产 | 输出直接继承的资产 |
| 输出资产 | 新路径或新版本，不得覆盖父资产 |
| 实际 Prompt | 案例 Prompt 文件链接；正文只保存在该文件 |
| 工具与模型 | 实际使用值 |
| 执行 ID | 实际调用 ID；没有时明确标记未知 |
| 变换步骤 | 生成、编辑、缩放、归一化等按发生顺序记录 |
| 规格与 SHA-256 | 输入、保留中间结果和输出的可检查值 |
| 已知边界 | 未保留的中间结果、历史表述偏差或不可验证事实 |

### 5. 验证生命周期

1. 每次验证记录验证对象、状态、依据和阻断问题。
2. `Needs work` 后的修正必须产生新变换或新版本。
3. `Pass` 只表示质量评估通过，不替代用户确认。
4. 用户确认后追加确认状态，不回写或删除此前状态。

## 不可变与单一事实源

1. 实际 Prompt 正文、调用、执行 ID、变换和历史结果一经记录不得润色或改写。
2. 发现历史记录不完整或不准确时，追加“已知边界”或新版本说明。
3. Prompt 正文只在案例 `Prompt/` 文件保存。
4. 来源关系、变换步骤、规格、哈希和验证生命周期只在案例 `生成记录.md` 完整保存。
5. 案例工作台和 Prompt 索引只保存状态、预览、简要映射和权威记录链接。

## 通用模板

```markdown
## 任务身份

- 顶层模式：复刻｜二次开发
- 输出资产身份：<用途与稳定路径>
- 用户确认的变更规格：<入口或摘要>

## 资产血缘

<根权威参考> --复刻--> <父资产> --二次开发--> <v1> --修正（二次开发）--> <v2>

## 资产清单

| 资产角色 | 文件与用途 | 规格 | SHA-256 |
|---|---|---|---|
| 根权威参考 | ... | ... | ... |

## 变换记录

### <阶段名称>

- 所属模式：...
- 派生关系：...
- 直接输入：...
- 直接父资产：...
- 输出资产：...
- 实际 Prompt：...
- 工具与模型：...
- 执行 ID：...
- 变换步骤：...
- 规格与 SHA-256：见资产清单中的直接输入与输出记录。
- 已知边界：...

## 验证生命周期

| 对象 | 状态 | 依据 | 后续 |
|---|---|---|---|
| ... | Needs work｜Pass｜用户已确认 | ... | ... |
```

模板中的链路仅展示字段关系，不代表固定阶段数量。没有发生二次开发或修正时，删除对应边，不创建空记录。
